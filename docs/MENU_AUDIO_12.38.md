# 메뉴 사운드와 음악 (12.38)

작성일: 2026-11-28

## 1. 메뉴 음악

### 1.1 곡

모든 곡은 VALOPRAC이 직접 작곡했습니다. 음원 파일 없이 브라우저(Web Audio)가 악보를 실시간으로 연주합니다. 그래서 내려받는 용량이 없고, 저작권 문제도 없습니다.

| 곡 | 장르 | 템포 | 조 | 화성 진행 |
|---|---|---|---|---|
| 야간 사격장 | 잔잔한 앰비언트 | 84 BPM | A 단조 | i–VI–III–v (2마디씩) |
| 네온 질주 | 신스웨이브 | 104 BPM | D 단조 | i–VI–III–VII |
| 로파이 집중 | 로파이 비트(스윙 62%) | 76 BPM | C 장조 | IV–iii–ii–I |
| 압박 | 긴장감 있는 전자음 | 128 BPM | A 화성 단조 | i–VI–iv–V (2마디씩) |
| 새벽 순찰 | 밝은 하우스 | 98 BPM | F 장조 | I–iii–vi–V |

- **곡 구성**: 도입부(한 번만) → A → B(멜로디) → 브레이크 → A로 반복합니다. 구간마다 악기 구성이 바뀌고, 구간 끝에는 필인과 라이저가 들어갑니다. 같은 곡도 마디마다 아르페지오·하이햇·필인이 조금씩 달라집니다. 정해진 규칙으로 바뀌므로, 같은 마디는 항상 같은 소리입니다.
- **무작위 재생**: 곡마다 최소 150초를 재생하고, 마디 경계에서 다음 곡으로 넘어갑니다.
- **곡 전환**: 이전 곡은 1.6초에 걸쳐 작아지고, 새 곡은 1.2초에 걸쳐 커집니다.
- **효과음과 조 맞추기**: 메뉴 효과음은 A와 E 음만 씁니다. 다섯 곡의 조는 모두 A와 E를 포함하므로 효과음이 음악과 부딪히지 않습니다.

### 1.2 설정

| 설정 | 기본값 | 위치 |
|---|---|---|
| 곡 | 야간 사격장 | 상단 음악 버튼, 설정 → 사운드 |
| 음악 음량 | 55% | 같음. 실제 크기 = 전체 음량 × 음악 음량 |
| 훈련 중에도 재생 | 꺼짐. 켜면 45% 크기 | 같음 |

- 브라우저는 사용자가 누르기 전에 소리를 낼 수 없습니다. 그래서 페이지를 처음 누르거나 키를 누를 때 음악이 시작됩니다.
- 탭을 숨기면 음악이 멈추고, 돌아오면 이어서 재생합니다.
- 음악을 끄면 소리가 작아진 뒤 오디오 처리도 멈춥니다.
- 훈련에 들어가면 음악이 꺼집니다("훈련 중에도 재생"을 켠 경우는 제외). 발소리를 듣는 연습을 방해하지 않기 위해서입니다.

### 1.3 측정 (Chromium에서 실제 렌더링)

| 곡 | 평균 크기(RMS) | 최대값 | 클리핑 |
|---|---|---|---|
| 야간 사격장 | −20.2 dBFS | −5.7 dBFS | 0 |
| 네온 질주 | −20.7 | −5.3 | 0 |
| 로파이 집중 | −20.9 | −5.2 | 0 |
| 압박 | −21.7 | −5.1 | 0 |
| 새벽 순찰 | −19.8 | −5.3 | 0 |

**음량과 음색**
- 다섯 곡의 평균 크기 차이는 2 dB 안입니다. 곡을 바꿔도 소리 크기가 크게 달라지지 않습니다.
- 처음 만든 믹스는 에너지의 74~85%가 200Hz 아래에 몰려 둔하게 들렸습니다. 4kHz 위 에너지는 0.4% 미만이었습니다.
- 악기별 균형과 마스터 EQ를 조정해, 100Hz 아래 비중을 8~35%로 낮췄습니다.

**CPU**
- 짧은 음(베이스, 아르페지오, 드럼 등)은 곡을 처음 재생할 때 한 번 렌더링해 두고 재사용합니다.
- 실시간 재생 중 Chromium 전체 CPU 사용량은 한 코어 기준 약 5~15%입니다. 측정 해상도는 5%입니다.

미리듣기는 개발 중에 같은 엔진으로 렌더링한 45초 MP3로 확인했습니다.

### 1.4 리플레이

음악 설정은 게임에 영향을 주지 않습니다. 그래서 리플레이 체크섬에서 뺐고, 음악 설정이 없는 이전 리플레이 파일도 그대로 열리고 검증됩니다(테스트로 확인).

## 2. 메뉴 효과음

게임 UI 사운드 설계의 공통 원칙(호버는 거의 들리지 않게, 확정·토글에 존재감, 앞으로·뒤로·오류는 서로 다르게, 0.05~0.5초, 음악의 조에 맞추기)을 따랐습니다.

| 소리 | 언제 | 길이 | 음 |
|---|---|---|---|
| 호버 | 마우스를 버튼·링크에 올릴 때(소리가 한 번 켜진 뒤) | 0.03초 | A6, 매우 작게 |
| 클릭 | 일반 버튼 | 0.072초 | 기존 둥근 탭 |
| 탭 이동 | 주 메뉴, 탭 | 0.12초 | E5 → A5 (올라감) |
| 뒤로·닫기 | 닫기·취소·뒤로 버튼 | 0.12초 | A4 → E4 (내려감) |
| 켜기 / 끄기 | 체크박스, 펼치기 | 0.075초 | E5↗A5 / A5↘E5 |
| 슬라이더 | 값을 움직일 때 | 0.016초 | E6, 값에 따라 음 높이 변화 |
| 훈련 시작 | 훈련 시작 버튼 | 0.5초 | A·E 화음 |
| 거부 | 비활성 버튼 | 0.15초 | 낮은 A2 두 번 |

- 모든 소리는 끝이 0으로 끝나 딸깍 소리가 나지 않습니다.
- 4kHz 위 에너지가 거의 없어 날카롭지 않습니다.
- 같은 소리는 너무 빨리 반복되지 않습니다. 호버와 슬라이더는 오디오를 새로 켜지 않습니다.
- 음량은 기존 "인터페이스 음량"을 따릅니다.
