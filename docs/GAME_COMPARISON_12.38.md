# VALOPRAC과 다른 게임 비교 (12.38)

작성일: 2026-11-28

VALOPRAC을 비슷한 목적의 게임 네 가지와 비교했습니다.
- **발로란트**, **카운터 스트라이크 2(CS2)**: VALOPRAC이 연습 대상으로 삼는 실제 경기 게임

이번 패치의 주제인 메뉴 사운드와 음악도 따로 비교했습니다.

## 1. 핵심 주제

| 게임 | 핵심 주제 | 연습의 위치 |
|---|---|---|
| 발로란트 | 5대5 전술 슈팅 + 요원 스킬. 정확한 첫 발과 멈춰서 쏘기 | 사격장은 경기 사이의 부가 기능 |
| CS2 | 5대5 전술 슈팅 + 경제·투척물. 반동 제어와 이동 기술 | 커뮤니티 서버·창작마당 맵으로 연습 |
| 에임랩 | 무료 에임 연습. 과제와 분석으로 약점 훈련 | 연습 자체가 게임 |
| 코박스 | 에임 연습. 수많은 사용자 시나리오와 플레이리스트 | 연습 자체가 게임 |
| **VALOPRAC** | **발로란트식 기본기 연습: 멈추는 정확도(톡브레이킹·카운터 스트레이핑·데드존), 피킹, 발소리 관리, 반동** | **연습 자체가 목적. 브라우저에서 바로 실행** |

VALOPRAC은 에임 연습 게임처럼 "연습 전용"입니다. 다만 훈련 대상이 에임만이 아니라 발로란트의 이동과 소리 규칙 전체입니다. 그래서 에임 연습 게임과 실제 경기 게임의 중간에 있습니다.

## 5. 메뉴 사운드와 음악 비교 (12.38)

| 항목 | 발로란트 | CS2 | VALOPRAC 12.38 |
|---|---|---|---|
| 음악 음량 | 전체 음악, 메뉴/로비, 요원 선택을 따로 | 메인 메뉴, 라운드 시작·종료, MVP, 10초 경고 등 장면별 | 전체 × 음악 음량, 훈련 중 재생 여부 |
| 곡 선택 | — (확인 못함) | 뮤직 키트로 전체 교체 | 5곡 + 무작위 재생 + 끄기 |
| 훈련·경기 중 | 요원 선택 음악은 경기 중에 안 나옴 | 장면별 음악. 많은 선수가 줄임 | 기본 꺼짐. 켜면 45% 크기 |
| 음성 대화 시 | 음악 줄이기 옵션 | — | 해당 없음(음성 대화 없음) |
| 메뉴 효과음 | 있음 | 있음 | 9종(아래) |

**메뉴 효과음의 공통 원칙과 적용**
- **위계**: 마우스를 올릴 때는 거의 들리지 않게 하고, 선택·확정·토글에만 분명한 소리를 냅니다. 호버는 0.03초로 가장 작고, 훈련 시작이 가장 큽니다.
- **구분**: 앞으로 가기, 뒤로 가기, 오류는 서로 다른 소리를 냅니다. 탭 이동은 올라가는 두 음, 닫기·뒤로는 내려가는 두 음, 비활성 버튼은 낮은 두 번의 울림입니다.
- **길이**: 마이크로 인터랙션 소리는 0.05~0.5초입니다. VALOPRAC은 0.016~0.5초입니다.
- **음 높이**: 음악의 조와 맞아야 거슬리지 않습니다. 효과음은 모두 A와 E 음이고, 메뉴 음악 5곡은 모두 이 두 음을 포함한 조로 썼습니다.
- **반복 방지**: 슬라이더 틱은 값에 따라 음 높이가 바뀌고, 같은 소리를 너무 빨리 반복하지 않습니다.

## 6. 정리

- **VALOPRAC의 고유한 점**
  - 발로란트 공개 수치에 맞춘 이동·정확도 규칙을 브라우저에서 측정하며 연습할 수 있습니다.
  - 소리(발소리, 점프, 착지)까지 훈련 대상입니다.
  - 리플레이가 결정론적으로 검증됩니다.
- **다른 게임에 있고 VALOPRAC에 없는 것**
  - 대규모 사용자 시나리오 공유(코박스)
  - 실제 맵 재현과 경기 기록 연동(에임랩)
  - 온라인 대전과 순위
- **이번 음악 기능**
  - 구조는 발로란트·CS2와 같습니다: 음악 음량 분리, 곡 선택, 경기 중 끄기.
  - 곡은 저작권 문제 없이 직접 작곡했고, 내려받을 파일 없이 브라우저에서 합성합니다.
