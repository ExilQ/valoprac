# 이동 물리 일관성 반복 검증 (12.34)

작성일: 2026-11-27 · 규칙 `consistency-v9`(리플레이 시뮬레이션 9) · 120Hz 고정 틱

말씀하신 세 가지와 "물리 시스템이 조금씩 다르다"는 문제를 검증했습니다. 실제 시뮬레이션을 반복 실행해 같은 기준을 모든 경우에 적용했고, 위반이 0이 될 때까지 고쳤습니다.

## 1. 검증 범위

| 검사 | 경우의 수 | 내용 |
|---|---|---|
| 점프 전수 검사 | 360 | 무기 4종 × 이륙 상태 10종 × 공중 동작 9종 |
| 지상 경로 검사 | 196 + 12 | 이동 상태 7종 사이의 모든 전환 × 무기 4종, 달리는 중 무기 교체 12가지 |
| 연속 점프 | 24 | 무기별 6연속 점프 |
| 무작위 세션 | 64 + 4 | 무작위 입력 480틱 세션 64개, 리플레이 정확 재생 4개 |

- **무기**: 밴달, 셰리프, 오퍼레이터, 칼
- **이륙 상태**:
  - 제자리, 달리기, 옆으로, 대각선, 뒤로, 걷기
  - 앉아 이동하다 점프, 앉음과 동시에 점프
  - 정조준 이동, 정조준 걷기
- **공중 동작**:
  - 없음, 앉기, 앉았다 일어서기, 일어서기, 걷기
  - 정조준, 키 떼기, 무기 교체, 스코프 켜기

### 기준

1. 점프는 지상 속도를 깎지 않습니다.
2. 공중에서 속도가 줄지 않습니다. 앉기, 일어서기, 걷기, 정조준, 무기 교체, 키를 떼는 경우 모두입니다.
3. 공중에서 속도가 오르는 폭은 공중 가속 규칙 안이어야 합니다. 이륙 속도 +0.75m/s 이하이고, 이륙 무기 속도의 1.05배 이하입니다.
4. 착지 속도는 공중 속도 범위 안에 있습니다.
5. 점프 소리는 이미 앉아 있던 이륙만 조용하고, 착지 소리는 앉은 채 이륙해 공중에서 일어선 경우만 조용합니다.
6. 지상 최종 속도는 이전 상태나 무기에 상관없이 같습니다.
7. 연속 점프는 무기 달리기 속도를 유지합니다.
8. 어떤 입력에서도 무기 달리기 속도의 1.10배를 넘지 않고, 리플레이는 정확히 재생됩니다.

## 2. 결과

| 규칙 | 점프 360가지 위반 |
|---|---|
| 12.22 (`bunny-hop-v5`, 현재 사이트) | 점프가 지상 속도를 깎음 54, 점프 소리 없음 324, 착지 소리 8 |
| 12.32~12.33 (`audio-v8`) | 점프가 지상 속도를 깎음 18, 착지 소리 8 |
| **12.34 (`consistency-v9`)** | **0** |

지상 경로, 무기 교체, 연속 점프, 무작위 세션, 리플레이 재생은 세 규칙 모두 위반이 없었습니다. 예외는 12.22의 칼 연속 점프로, 5.67m/s에 묶였습니다.

## 3. 말씀하신 문제별 결과

### 3.1 칼을 들고 점프하면 속도가 줄어듦 → 고침

- **원인**: 공중 속도 상한(점프 속도 1.05배, 공중 상한 1.05배, 연속 점프 1.10배)이 라이플 속도 5.4m/s 기준으로 고정돼 있었습니다.
- **12.22(현재 사이트)**: 칼을 들고 점프하면 항상 6.75에서 5.67m/s로 떨어졌고, 연속 점프도 5.67m/s에 묶였습니다.
- **12.32**: 달리기 점프는 고쳤지만, 뒤로 점프(6.21 → 5.94)와 앉음과 동시에 점프(6.75 → 5.94)는 아직 깎였습니다.
- **12.34**: 모든 상한이 이륙 무기의 달리기 속도에 비례합니다. 칼은 어느 방향, 어느 자세로 점프해도 지상 속도를 유지합니다.

### 3.2 앉고 점프한 뒤 공중에서 일어서면 → 착지 소리 없음

미리 앉은 채 점프하면 공중에서 일어설 때 다리가 아래로 펴집니다. 그래서 더 일찍 착지하고 착지 속도도 낮습니다. 커뮤니티에 알려진 발로란트의 조용한 착지 기법과 같은 원리입니다.

| 점프 | 체공 | 착지 충격 속도 | 착지 소리 |
|---|---|---|---|
| 서서 점프 | 0.675초 | 6.90m/s | 남 |
| 앉아서 점프, 그대로 착지 | 0.683초 | 7.07m/s | 남 |
| 점프 후 공중에서 앉기 | 0.742초 | 8.27m/s | 남 |
| **앉아서 점프, 공중에서 일어서기** | **0.600초** | **5.37m/s** | **안 남** |

- 착지 충격 속도가 6.0m/s보다 낮으면 착지 소리가 나지 않습니다. 이전에는 거의 모든 착지에서 소리가 났습니다.
- 높이로 환산하면 0.88m보다 낮은 곳에서 떨어지면 조용합니다. 평지에서 서서 점프하면 0.675초 체공하고 6.90m/s로 착지하므로 여전히 소리가 납니다.
- 미리 앉아 이동하다 점프하면 이륙 속도는 앉아 이동 속도(라이플 1.944m/s)입니다. 공중에서 일어서면 공중 가속 규칙에 따라 최대 +0.75m/s까지 오릅니다.
- 이 조용한 착지 판정은 커뮤니티 설명과 말씀하신 동작에 맞춘 것입니다. Riot의 공식 값은 아닙니다.

### 3.3 줌하고 움직일 때 속도

정조준 속도가 줄어드는 것은 공식 값과 같습니다.

| 상태 | 속도 | 기준 |
|---|---|---|
| 밴달·팬텀 정조준 이동 | 4.104m/s (76%) | 공식 위키 |
| 오퍼레이터 저격 조준 이동 | 3.694m/s (72%, 2.5배·5배 같음) | 팬 위키 |
| 셰리프 | 정조준 없음, 5.4m/s | — |

일관성 검사에서 정조준과 관련된 차이는 없었습니다.

- 정조준을 켜고 끄는 순서와 상관없이 지상 최종 속도가 같습니다.
- 공중에서 정조준이나 스코프를 켜도 속도가 바뀌지 않습니다.
- 정조준 이동 중 점프해도 4.104m/s를 유지합니다.

## 4. 바꾸지 않은 것

- **공중 가속**: 제자리 점프 뒤 방향키로 움직이거나, 공중에서 일어서거나 무기를 바꾸면 속도가 약간 오릅니다. 모두 같은 규칙(이륙 속도 +0.75m/s 이하, 이륙 무기 속도의 1.05배 이하)을 따르므로 계산 방식의 차이는 아닙니다.
- **걷기 48%, 앉아 이동 36%, 뒤로 92%**: 공식 값이 없어 그대로 뒀습니다(12.32 보고서 참고).
