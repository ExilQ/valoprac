# VALOPRAC 12.31 — 봇 재등장, 봇 시점 리플레이, 공중 앉기, 탄창 무한
2026년 11월 26일 · 훈련 기능 패치

훈련 맵에서 쓰러진 봇이 다시 나타나고, 봇이 총소리에 반응합니다. 리플레이를 봇의 눈으로 볼 수 있고, 점프 중 앉으면 머리 대신 다리가 올라갑니다. 재장전 없이 계속 쏘는 탄창 무한 옵션도 추가했습니다.

## 봇 재등장

- **적용 맵**: 전술 코스 13개, 전술 맵, 피킹 연구실, 관통 훈련 맵
- **동작**
  - 쓰러진 봇이 기본 3초 뒤 다시 나타납니다.
  - 나타나는 자리는 원래 방어각이나 그 각의 다른 검증된 위치 중 한 곳입니다. 매번 같은 자리를 외워서 칠 수 없습니다.
- **설정**: 표적 설정에 "쓰러진 봇 다시 등장"(기본 켜짐)과 "다시 등장까지"(0.5~10초)가 있습니다. 끄면 이전처럼 모두 제거한 뒤 직접 초기화합니다.
- **화면 표시**: 재등장이 켜져 있으면 화면 위 진행 표시가 "각 N개 완료" 대신 누적 처치 수를 보여 줍니다.

## 봇 AI 개선

- **총소리 반응**: 봇이 총소리를 듣습니다. 60m 안에서 쏘면 플레이어가 보이지 않는 봇도 소리가 난 쪽으로 조준을 돌리고 경계합니다. 소음기가 달린 팬텀은 40m입니다. 벽이나 엄폐물에 막히면 들리는 거리가 70%로 줄어듭니다(발소리와 같은 규칙).
- **예측하기 어려운 재등장**: 다시 나타나는 위치가 매번 달라, 같은 각을 같은 방식으로만 잡는 연습이 되지 않습니다.
- **판단 방식은 그대로**: 봇은 계속 실제 시야, 발소리, 총소리로만 판단합니다. 벽 너머를 보는 판단은 없습니다.

## 봇 시점 리플레이

리플레이 화면의 카메라 버튼에 **봇 시점**을 추가했습니다. 봇이 있는 맵에서만 나타납니다.

- **카메라**
  - 봇의 눈 위치에서 봇이 실제로 조준한 방향을 봅니다. 반동으로 흔들린 조준도 그대로 보입니다.
  - 조준 모터가 없는 봇은 플레이어 쪽을 봅니다.
- **봇 선택**: 봇이 여러 명이면 볼 봇을 고를 수 있습니다.
- **함께 보이는 정보**
  - 화면 아래 표시에 봇의 상태가 나옵니다: 각 유지, 소리 확인, 경계, 추적, 사격, 반동 회복, 자리 이동, 다시 피킹, 제자리 복귀
  - 봇이 쓰러졌다가 다시 나타나기 전까지는 "쓰러짐 · 다시 나타날 때까지 대기"로 표시됩니다.
- **플레이어 표시**: 내 위치는 반투명 실루엣으로 보입니다. 봇이 나를 언제, 어디서 발견했는지 확인할 수 있습니다.

카메라는 화면 표시만 바꿉니다. 리플레이 검증과 점수에는 영향이 없습니다.

## 공중 앉기: 머리 대신 다리가 올라감

점프 중 앉기를 누르면 이제 머리가 내려가지 않고 다리가 올라갑니다.

| 항목 | 이전 | 현재 |
|---|---|---|
| 눈높이 | 앉는 만큼 내려감 | 거의 그대로 |
| 발 높이 | 그대로 | 최대 0.5m 올라감 |
| 착지 시점 (제자리 점프 후 앉기) | 0.675초 | 0.733초 (약 0.06초 늦음) |

- 다리를 들어 올린 만큼 더 높은 곳에 올라설 수 있습니다.
- 공중에서 일어서면 다리를 다시 내립니다. 아래가 바닥이면 바닥에 딱 맞게 내려섭니다.

## 탄창 무한

탄약 설정에 **탄창 무한 · 재장전 없음**을 추가했습니다.

- 쏴도 탄창이 줄지 않아 재장전 없이 계속 쏠 수 있습니다.
- 연사 속도와 반동은 그대로입니다.
- 켜면 "예비 탄약 무제한"과 "자동 재장전" 설정은 숨겨집니다. 탄창이 줄지 않아 필요가 없기 때문입니다.

## 무기별 이동 속도 (확인 결과 변경 없음)

공식 위키의 무기별 이동 속도와 비교했습니다. VALOPRAC은 이미 같은 값을 씁니다.

| 슬롯 | 무기 | 달리기 속도 |
|---|---|---|
| 1 주무기 | 밴달·팬텀 | 5.4m/s |
| 1 주무기 | 오퍼레이터 | 5.13m/s |
| 2 보조무기 | 셰리프 | 5.4m/s |
| 3 칼 | 칼 | 6.75m/s |

셰리프의 공식 달리기 속도는 라이플과 같은 5.4m/s입니다. 그래서 밴달·팬텀과 셰리프를 바꿔도 속도가 같습니다. 클래식, 고스트처럼 더 빠른(5.73m/s) 권총은 VALOPRAC에 없습니다. 원하시면 가벼운 권총을 보조무기로 추가할 수 있습니다.

## 기존 리플레이 호환

새 동작(봇 재등장, 총소리 반응, 공중 앉기)은 새 시뮬레이션 규칙(`training-v7`, 리플레이 시뮬레이션 7)에만 적용됩니다.

- 이전 버전 리플레이는 녹화 당시 규칙으로 그대로 재생·검증됩니다.
- 새로 추가한 설정 항목이 없는 이전 리플레이 파일도 그대로 열립니다.
- 이전 규칙의 보정값 지문과 체크섬이 바뀌지 않았는지 기존 테스트로 확인했습니다.

## 검증

- 애플리케이션 테스트, hosting 테스트, broker 테스트 전부 통과
- 타입 검사, 전체 빌드 검증 체인(`pnpm build`) 통과
- 새 테스트
  - 봇이 설정한 시간 뒤 원래 각이나 다른 검증된 위치에 다시 나타나는지, 끄거나 이전 규칙이면 나타나지 않는지
  - 공중 앉기에서 발이 올라가 착지가 늦어지고, 눈높이가 갑자기 내려가지 않는지
  - 총소리가 들리는 거리 안의 봇만 반응하는지, 이전 규칙에서는 반응하지 않는지
  - 탄창 무한일 때 탄창이 줄지 않는지
  - 실제 입력으로 봇을 쓰러뜨리고, 재등장·총소리·공중 앉기가 들어간 리플레이가 정확히 재생되는지
  - 봇 시점 카메라가 봇의 눈 위치와 실제 조준 방향을 쓰는지
  - 새 화면 문구가 영어 화면에서 모두 번역되는지
