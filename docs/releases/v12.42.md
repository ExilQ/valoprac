# VALOPRAC 12.42 — 케인제라 스타일 봇 무빙 추가
2026년 11월 28일 · 봇 무빙 패치

멈추지 않고 빠르게 좌우로 흔들다가, 방향을 바꾸는 순간 한 발씩 쏘는 케인제라 스타일 봇 무빙을 추가했습니다. 고르는 곳은 전술 맵 → 훈련 환경 세부 설정 → 봇 무빙 → 프로 선수 무빙 참고입니다. "무작위"에도 포함됩니다.

## 동작

- 완전히 멈추지 않는 좌우 무빙입니다.
- 방향을 바꿀 때 속도가 데드존 아래로 지나가는 순간 한 발을 쏩니다. 모든 사격이 한 발입니다.
- 짧은 이동(0.12~0.2초)과 긴 이동(0.3~0.42초)을 섞습니다.
- 25%는 같은 방향으로 대충 브레이킹해 한 발 쏜 뒤 계속 이동합니다.

## 측정

- 방향 전환마다 저속 구간이 약 0.11초입니다. 완전히 멈추지 않습니다.
- 사격은 0.4~1.4m/s, 즉 데드존(1.485m/s) 아래를 지나가는 중에 나갑니다.
- 좌우 폭은 4.6m입니다.

## 근거

- 공유해 주신 ChatGPT 대화의 설명을 근거로 했습니다: "빠르게 좌우로 움직여 상대의 에임을 흔들면서, 방향을 전환하는 순간 한 발씩 정확하게 꽂는 무빙", "고속 스트레이핑 + 데드존 원탭 + 불규칙한 리듬 변화", "짧게 → 길게 → 짧게", "같은 방향 재이동".
- 그 대화도 선수의 실제 키 입력을 검증한 것은 아니라고 밝히고 있습니다. 선수를 분석한 공개 자료도 없어서, 연습용 근사입니다.
- 첫 번째 대화의 선수별 분석 답변은 공유 페이지에 표시되지 않아 반영하지 못했습니다.

- 애플리케이션 테스트, hosting 테스트, broker 테스트 전부 통과
- 타입 검사, 전체 빌드 검증 체인(`pnpm build`) 통과
- 새 테스트
  - 완전히 멈추지 않는지
  - 모든 사격이 한 발이고 데드존 아래 속도에서 나가는지
  - 움직이는 중에 쏘는지(0.3m/s 이상)
  - 좌우 폭
