# VALOPRAC 12.35 — 속도 회복에 실제 같은 지연
2026년 11월 27일 · 이동 보정 패치

멈춘 상태나 걷기·앉기·정조준에서 다시 달릴 때 최고 속도로 너무 빨리 돌아왔습니다. 가속 값을 근거에 맞춰 바꿨습니다.

## 판단 근거

| 항목 | 12.34까지 | 발로란트 쪽 자료 |
|---|---|---|
| 정지 → 최고 속도 95% (라이플) | 0.14초 | 0.258초 (발로란트 이동을 재현한 프로젝트의 추정치) |
| 키를 떼고 25%까지 | 0.133초 | 0.110초 (Riot 개발자 공개 수치, 팬텀) |
| 키를 떼고 완전 정지 | 0.192초 | 0.170초 (같은 자료) |

- **가속**: 추정치보다 약 2배 빨랐습니다. 발로란트는 언리얼 엔진 기반이고, 언리얼 캐릭터 이동의 기본 최대 가속도는 2048cm/s²(20.48m/s²)입니다. 이 값으로 가속하면 95%까지 0.258초가 걸려 추정치와 맞습니다.
- **정지**: 정지 시간은 이미 Riot 수치와 20ms 안쪽이라 이번에는 바꾸지 않았습니다.
- **출처의 한계**: 가속 시간은 공식 값이 아니라 추정치입니다. Riot 수치는 2020년 공개된 내용을 정리한 자료로 확인했습니다.

## 바뀐 점

새 가속은 정지에서 출발할 때와, 걷기·앉기·정조준을 풀고 다시 달릴 때 모두 적용됩니다.

| 최고 속도 95%까지 | 12.34 | 12.35 |
|---|---|---|
| 정지 → 달리기 (라이플) | 0.142초 | **0.258초** |
| 정지 → 달리기 (오퍼레이터) | 0.133초 | **0.242초** |
| 정지 → 달리기 (칼) | 0.175초 | **0.317초** |
| 걷기 → 달리기 (라이플) | 0.075초 | **0.125초** |
| 앉기 → 달리기 (라이플) | 0.117초 | **0.158초** (일어서는 시간 0.125초 포함) |
| 정조준 → 달리기 (라이플) | 0.033초 | **0.058초** |

- **바뀌지 않은 것**: 멈추는 시간(키를 떼면 25%까지 0.133초, 정지까지 0.192초)과 반대키로 멈추는 시간은 그대로입니다.
- **발소리**: 출발 직후 가속이 느려져, 정지 상태에서 짧게 움직일 때 발소리가 나기까지 조금 더 걸립니다.

## 함께 고친 것

Unreal 포팅용 C++ 코어의 설정 파일이 12.27 무기 수치 변경 이후 다시 생성되지 않고 남아 있었습니다(예비 탄약 75·90, 공중 오차 8.5 등). 이번 가속을 포함한 현재 규칙으로 다시 생성했고, 브라우저 시뮬레이션과 결과가 같은지 확인하는 기존 테스트도 통과합니다.
