# VALOPRAC 12.22 — 그래픽 옵션·성능 개선, 훈련장 재질, 칼 슬롯
2026년 11월 26일 · 통합 패치

동시에 진행된 두 개발 흐름을 하나로 합친 버전입니다. 그래픽 옵션·성능 개선, 훈련장 재질·조명 개선, 그리고 칼·무기 슬롯과 무기 전환 멈춤 수정이 모두 들어 있습니다.

> **버전 번호 안내**: GitHub의 [v12.21](https://github.com/ExilQ/valoprac/releases/tag/v12.21) 릴리스는 "칼 슬롯과 무기 전환 수정"입니다. 같은 시기에 `production` 브랜치에서는 "훈련장 재질·조명·색감 개선"이 앱 안에서 12.21로 따로 배포됐습니다. 12.22는 이 두 가지를 모두 포함하며, 앱의 패치 노트에서는 칼 관련 변경을 12.22 항목에 적었습니다.

## 그래픽 옵션과 성능

- 최고 품질이 더 이상 화면을 1.25배로 키워 그리지 않습니다. 그리는 해상도는 창 크기·화면 배율과 상관없이 4K(3840×2160)를 넘지 않습니다.
- 보통·높음은 화면 전체 후처리 없이 기본 안티에일리어싱(MSAA)만 씁니다. 주변광 차폐와 빛 번짐은 최고 품질에만 남겼고, FXAA는 없앴습니다.
- 주변광 차폐 샘플 수를 절반(16)으로 줄이고, 그림자는 더 가볍고 선명한 방식으로 바꿨습니다.
- 매 프레임 조준선 스타일을 다시 쓰던 부분을 고쳐, 끊김(스터터)의 원인 하나를 없앴습니다.
- 기본값 그대로인 그래픽 설정은 처음 실행할 때 새 기준으로 옮겨집니다. 직접 바꾼 설정은 그대로 둡니다.

## 훈련장 재질·조명·색감

- 표적 가장자리에 옅은 윤곽 빛이 생깁니다. 설정 → 그래픽에서 빨강·노랑·보라를 고르거나 끌 수 있습니다.
- 햇빛은 강하게, 하늘빛은 약하게 조정하고 색을 그대로 살리는 톤 매핑(Khronos PBR Neutral)으로 바꿔, 화면이 뿌옇게 보이지 않습니다.
- 높음 품질의 재질 해상도를 두 배로 올리고, 벽·바닥 이음선을 가늘고 깔끔하게 다듬었습니다.

## 무기 슬롯과 칼 (GitHub v12.21 내용)

- **무기 전환 시 멈춤 수정**: 이동 키를 누른 채 숫자 키로 무기를 바꾸면 캐릭터가 멈추던 문제를 고쳤습니다.
- **고정 슬롯**: `1` 주무기(마지막으로 고른 밴달·팬텀·오퍼레이터), `2` 셰리프, `3` 칼.
- **칼**: 좌클릭 베기(피해 50, 사거리 2.2m), 우클릭 찌르기(피해 75, 사거리 1.9m). 칼을 들면 6.75m/초로 더 빨리 달립니다. 칼 공격은 사격 통계에 들어가지 않습니다.
- **칼 디자인 6종**: 실제형(필드 나이프·탄토·카람빗·쿠나이)과 판타지(에테르 블레이드·흑요석 송곳니). 무기 화면에서 고를 수 있습니다.

## 기록·리플레이

- 리플레이 파일 형식과 기존 리플레이의 검증 결과는 바뀌지 않았습니다. 윤곽 빛과 그래픽 설정은 표시 설정이라 리플레이 체크섬에 영향을 주지 않습니다.

## 검증

- 두 흐름을 합친 뒤 다시 검증했습니다: 애플리케이션 테스트 1,540개, broker 테스트 28개, hosting 테스트 30개 통과, 타입 검사·릴리스 검증·번들 빌드 통과.
- 그래픽 성능 수치는 소프트웨어 렌더러(SwiftShader)에서 잰 상대 비교입니다. 실제 GPU에서의 프레임은 측정하지 않았습니다. 자세한 내용: [그래픽 성능 감사](https://github.com/ExilQ/valoprac/blob/v12.22/docs/GRAPHICS_PERFORMANCE_12.22.md) · [재질·조명 개선](https://github.com/ExilQ/valoprac/blob/v12.22/docs/MATERIALS_REFRESH_12.21.md)
- 확인하지 못한 항목: 실제 GPU 렌더링, 실제 마우스 잠금 상태에서의 조작감, Safari/Firefox. 전체 `pnpm build`는 Git에 없는 QA 비교 이미지 때문에 새 체크아웃에서 `verify-build` 단계에서 멈춥니다(이전부터 있던 문제).

Unreal Engine 런타임과 GPU 성능은 이 버전에서 검증하지 않았습니다.
