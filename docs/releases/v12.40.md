# VALOPRAC 12.40 — 상대 봇 무빙 9가지와 연습 봇 외형
2026년 11월 28일 · 봇 패치

봇이 엄폐물에서 피킹하며 9가지 무빙으로 교전합니다. 직접 고르거나 무작위로 만날 수 있습니다. 봇 외형은 어느 맵에서도 잘 보이게 바꿨습니다. 12.39 최적화 뒤 그래픽이 깨지지 않았는지도 전수 검증했습니다.

## 봇 무빙

**고르는 곳**: 전술 맵 → 훈련 환경 세부 설정 → 상대 봇 무빙 · 외형

| 분류 | 무빙 |
|---|---|
| 피킹 방법 | 빠른 템포 근접 교전, 와이드 피킹, 지글 후 앉아 피킹, 팝핀 스윙 |
| 프로 선수 무빙 참고 | 썸띵(불규칙 ADAD), 프리미(앉았다 일어서기), 플래시백(앉아서 좌우 이동), 텍스처(빠른 템포 선사격), 카론(브레이킹 때 앉기) |
| 무작위 | 봇마다 다른 무빙 |

**동작**
- 봇이 엄폐물 쪽을 스스로 찾아 숨었다가 피킹합니다.
- 플레이어를 보면 스타일별 이동·멈춤(사격) 구간과 앉기로 교전합니다.
- 가속·감속·앉기 시간은 플레이어와 같은 발로란트 기준입니다.
- 봇도 정확도 규칙을 지켜, 멈춰서 데드존 아래로 느려졌을 때나 앉아 걸을 때만 쏩니다.
- 마지막 제거 분석에 상대 봇의 무빙이 표시됩니다.

**측정 예**
- 팝핀 스윙: 좌우 폭 8.9m, 멈춤 0.05초
- 와이드 피킹: 한 번에 0.6초 이동
- 빠른 템포 근접 교전: 11m에서 3.6m까지 접근
- 플래시백 스타일: 이동 중 100% 앉음
- 카론 스타일: 멈출 때 99% 앉음

**출처와 한계**
- 선수 무빙은 공개된 설명(팝핀 스윙 해설, 무빙 분석 글, 커뮤니티 의견)을 바탕으로 만든 연습용 근사입니다. 해당 선수와 관련이 없습니다.
- 출처와 한계는 `docs/BOT_MOVEMENT_12.40.md`에 정리했습니다.
- "케인제라" 무빙은 어떤 선수인지 찾지 못해 넣지 않았습니다.

## 연습 봇 외형

- 이전 봇은 청록 재킷·살구색 피부라 맵의 청록 띠·베이지 벽과 섞였습니다.
- 바뀐 디자인
  - 어두운 몸체
  - 주황 어깨와 노랑 테두리
  - 회색 마네킹 얼굴
  - 어두운 헬멧과 밝은 눈
- 8m에서 배경 대비 밝기 차이가 19~33% 커졌습니다.
- 판정 범위는 같습니다. 설정에서 기존 요원 외형도 고를 수 있습니다.

## 그래픽 검증

- 맵 8개 × 품질 4단계, 32개 장면을 12.38과 비교해 모든 픽셀이 같았습니다.
- WebGL·콘솔 오류는 0건이었습니다.
