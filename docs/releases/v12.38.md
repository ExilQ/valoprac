# VALOPRAC 12.38 — 메뉴 음악과 메뉴 효과음
2026년 11월 28일 · 사운드 패치

직접 작곡한 메뉴 음악 5곡을 추가했습니다. 곡을 고를 수 있고, 음악 음량을 따로 조절할 수 있습니다. 메뉴 효과음도 다른 게임들의 UI 사운드 원칙에 맞춰 다시 만들었습니다.

## 메뉴 음악

| 곡 | 장르 | 템포 |
|---|---|---|
| 야간 사격장 (기본) | 잔잔한 앰비언트 | 84 BPM |
| 네온 질주 | 신스웨이브 | 104 BPM |
| 로파이 집중 | 로파이 비트 | 76 BPM |
| 압박 | 긴장감 있는 전자음 | 128 BPM |
| 새벽 순찰 | 밝은 하우스 | 98 BPM |

- **곡**: 모두 VALOPRAC이 직접 작곡했습니다. 음원 파일 없이 브라우저가 실시간으로 연주하므로 내려받는 용량이 없습니다.
  - 곡은 도입부 → A → B(멜로디) → 브레이크 순으로 이어지고 반복됩니다.
  - 같은 곡도 마디마다 조금씩 달라집니다.
- **고르는 곳**: 상단의 음악 버튼, 또는 설정 → 사운드 → 메뉴 음악
  - 다섯 곡 중 하나, 무작위 재생(곡마다 약 2분 30초), 끄기를 고를 수 있습니다.
  - 곡을 바꾸면 이전 곡이 작아지면서 새 곡으로 넘어갑니다.
- **음악 음량**: 효과음과 따로 조절합니다(기본 55%). 실제 크기는 전체 음량 × 음악 음량입니다.
- **훈련 중**: 발소리를 듣는 연습을 방해하지 않도록 음악이 꺼집니다. "훈련 중에도 재생"을 켜면 45% 크기로 계속 재생합니다.
- **재생 조건**
  - 브라우저 정책상 페이지를 처음 누르거나 키를 누를 때 음악이 시작됩니다.
  - 탭을 숨기면 멈추고, 돌아오면 이어서 재생합니다.
- **측정**: 다섯 곡 모두 평균 크기 차이 2 dB 이내, 클리핑 없음입니다. 실시간 재생 CPU는 한 코어 기준 약 5~15%입니다.

## 메뉴 효과음

이전에는 모든 버튼이 같은 소리를 냈습니다. 이제 종류별로 9가지 소리를 냅니다.
- **호버**: 마우스를 버튼에 올리면 아주 작게 납니다(0.03초).
- **클릭**: 일반 버튼
- **탭 이동**: 올라가는 두 음
- **뒤로·닫기**: 내려가는 두 음
- **켜기·끄기**: 체크박스와 펼치기. 켜면 올라가고 끄면 내려갑니다.
- **슬라이더**: 값에 따라 음 높이가 바뀌는 짧은 틱
- **훈련 시작**: 화음
- **비활성 버튼**: 낮은 두 번의 울림

원칙은 다른 게임의 UI 사운드와 같습니다.
- 확정·토글은 분명하게, 호버는 거의 들리지 않게 합니다.
- 오류는 확정과 다른 소리를 냅니다.
- 음악과 같은 조로 맞춥니다. 효과음은 모두 A·E 음이고, 다섯 곡 모두 이 음이 들어간 조입니다.

## 검증

- 애플리케이션 테스트, hosting 테스트, broker 테스트 전부 통과
- 타입 검사, 전체 빌드 검증 체인(`pnpm build`) 통과
- 새 테스트(`menu-audio-1238`)
  - 곡이 정해진 규칙대로 생성되는지, 마디 안에 있는지, 조 밖의 음이 없는지
  - 곡 구성과 무작위 재생 길이
  - 효과음 9종의 길이·끝점·고음 성분·크기 위계
  - 버튼 종류별 소리 선택
  - 설정값 검증과 영어 화면
- Chromium에서 다섯 곡을 실제로 렌더링해 크기·클리핑·음색 균형을 측정했습니다.
- 데스크톱과 모바일 화면에서 음악 창이 동작하는지 확인했습니다.
- 훈련에 들어가면 음악 오디오가 멈추는 것도 확인했습니다.
- 게임 규칙과 리플레이는 바뀌지 않았습니다(리플레이 시뮬레이션 12 그대로).
