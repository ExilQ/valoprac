# VALOPRAC 12.24 — 사운드 전면 개선
2026년 11월 26일 · 사운드 패치

모든 소리를 다른 FPS 게임의 사운드 설계 방식에 맞춰 다시 만들었습니다. 총소리, 재장전, 명중·처치음, 발소리, 탄착음, 그리고 소리가 울리는 공간까지 바뀌었습니다. 지금도 모든 소리는 코드로 직접 합성하며, 어떤 게임의 녹음도 쓰지 않습니다.

## 이전 소리의 문제

- 총소리가 짧은 잡음 뒤로 **같은 음 하나가 소리 끝까지 계속 울리는** 구조였습니다. 총소리라기보다 "웅" 하는 울림에 가까웠고, 셰리프는 두 음이 0.6초 동안 울렸습니다.
- 재장전·볼트 소리는 높은 "쉭" 잡음뿐이었습니다(주파수 중심 9~10kHz).
- 헤드샷 확인음은 높은 사인파였고, 몸 명중은 무기 장착음을 작게 재생하는 방식이었습니다.
- 모든 소리가 모노였고, 공간 울림이 없었으며, 같은 소리가 매번 똑같이 반복됐습니다.

## 다른 게임들과 비교해 반영한 점

- **총소리를 여러 겹으로 만들고 여러 변형을 번갈아 재생합니다.** 게임 무기 사운드는 기계음·타격·몸통·저음·꼬리로 나누어 만들고, 공간 잔향은 엔진이 맵에 맞게 붙이며, 같은 소리 반복을 피하려고 변형을 돌려 씁니다.
- **발소리는 거리감보다 잘 들리는 것을 우선합니다.** VALORANT 오디오 디렉터가 밝힌 방식으로, 거리 감쇠를 완만하게 했습니다.
- **명중 피드백을 중요하게 다룹니다.** CS2는 몸샷 명중음이 늦게 들리는 문제를 따로 패치할 만큼 이를 중시합니다.

## 변경 사항

- **총소리**: 기계음, 날카로운 파열음, 몸통 소리, 음정이 떨어지는 묵직한 저음, 짧은 꼬리를 겹쳐 만듭니다. 총마다 네 가지 변형을 번갈아 재생해 연사할 때 같은 소리가 반복되지 않습니다.
  - 밴달: 단단한 파열음과 묵직한 저음
  - 팬텀: 소음기의 "푹" 하는 공기음과 또렷한 노리쇠 소리
  - 셰리프: 큰 폭발음과 짧게 울리는 총신
  - 오퍼레이터: 거대한 저음과 긴 잔향
- **내 총소리는 스테레오입니다.** 다른 사람이 쏜 총은 3인칭 소리로, 기계음이 빠지고 더 둔하게 들립니다.
- **재장전·장착**: 탄창 분리 딸깍 → 탄창 빠짐 → 새 탄창 장착 "철컥" → 장전 손잡이 순서로 들립니다. 셰리프는 실린더를 열어 탄피 여섯 개를 털어내고 닫으며, 오퍼레이터는 볼트를 들고·당기고·밀고·잠급니다.
- **명중·처치음**
  - 헤드샷: 짧은 금속성 "딩" (0.18초 안에 사라짐)
  - 몸샷: 둔탁한 "퍽"
  - 처치: 처치할 때마다 두 음짜리 확인음이 울리고, 2.5초 안에 연속으로 처치하면 한 단계씩 음이 올라갑니다(칼 처치 포함).
- **발소리·착지**: 뒤꿈치와 앞꿈치가 30~40밀리초 간격으로 바닥에 닿는 소리입니다. 철판은 울리고, 나무는 속이 빈 소리, 유리는 밝은 소리가 나며, 바닥마다 네 가지 변형이 있습니다. 착지에는 몸이 떨어지는 소리와 장비가 흔들리는 소리가 더해졌습니다.
- **탄착음**: 콘크리트는 깨지며 부스러기가 떨어지고, 금속은 "팅" 하고 튕기며, 나무는 둔하게 쪼개지고, 유리는 깨지며 짤랑거립니다.
- **공간과 거리**: 맵마다 다른 울림이 붙습니다(사격장 1.15초, 야외형 맵 0.8초, 실내형 0.52초). 멀리서 난 소리는 고음이 줄고 울림이 더 크게 들려 거리가 느껴집니다.
- **마스터 출력**: 압축기와 리미터를 걸어 여러 소리가 겹쳐도 찌그러지지 않습니다.
- **끊김 없음**: 소리는 훈련 시작 화면이 열려 있는 동안 별도 스레드에서 미리 만들어 둡니다. 실제 빌드에서 훈련을 시작한 뒤 50밀리초가 넘는 끊김은 없었습니다.
- 설정 → 사운드에서 직접 등록한 녹음(권한 있는 파일)은 지금처럼 총소리와 헤드샷 확인음을 대신합니다.

## 측정 (48kHz로 합성한 신호를 분석)

| 총소리 | 주파수 중심 | 저음(150Hz 미만) 비중 | 스테레오 폭 |
|---|---|---|---|
| 밴달 | 284 → 859Hz | 49% → 28% | 0 → 0.15 |
| 팬텀 | 494 → 1164Hz | 73% → 19% | 0 → 0.12 |
| 셰리프 | 288 → 774Hz | 0% → 21% | 0 → 0.20 |
| 오퍼레이터 | 1088 → 625Hz | 51% → 28% | 0 → 0.24 |

헤드샷 확인음 주파수 중심 1120 → 3135Hz, 콘크리트 발소리 4882 → 2133Hz.

## 검증

- 애플리케이션 테스트 1,552개, broker 테스트 28개, hosting 테스트 30개 통과, 타입 검사·릴리스 검증·번들 빌드 통과.
- 새 테스트: 1인칭 스테레오·3인칭 모노, 변형이 서로 다르고 재현 가능한지, 저음에 치우치지 않는지, 파열음이 3밀리초 안에 시작하는지, 헤드샷·몸샷 구분, 연속 처치 음 상승, 모든 미리 만드는 소리 생성, 맵별 울림.
- 실제 빌드 브라우저에서 확인: 소리 생성 스레드가 로드되고 오류가 없었으며, 훈련 중 소리 39개가 재생됐습니다.
- 확인하지 못한 항목: **사람이 직접 들어 본 평가**, 헤드폰에서의 방향감, 실제 게임 녹음과의 비교. 위 수치는 신호를 잰 것이지, 소리가 얼마나 좋은지를 증명하지 않습니다.
