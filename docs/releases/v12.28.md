# VALOPRAC 12.28 — 리뷰 반영: 리플레이 호환, 잔향 볼륨, 칼 판정
2026년 11월 26일 · 수정 패치

사이트에 반영하기 전에 PR 코드 리뷰(Codex 자동 리뷰)가 지적한 세 가지를 실제 코드와 테스트로 확인했습니다. 셋 다 실제 결함이어서 고쳤습니다.

## 고친 문제

- **이름이 바뀐 코스의 옛 리플레이가 실패함 (12.27에서 생긴 문제)**
  - 코스 이름이 리플레이 검증 상태(체크섬)에 포함돼 있었습니다. 그래서 12.27에서 이름을 바꾸자, 그 전에 녹화한 13개 코스의 리플레이가 첫 검증 지점에서 실패했습니다. 12.27 노트에 "기록이 그대로 이어진다"고 적었지만, 리플레이는 그렇지 않았습니다.
  - 이제 이전 버전(규칙 v2~v5) 리플레이는 녹화 당시 코스 이름으로 검증합니다.
  - 12.26 코드로 직접 녹화한 리플레이 3개(전이문 마당, 세 갈래 정원, 냉동 적재장)를 테스트에 넣어, 실패를 재현한 뒤 통과하는 것을 확인했습니다.
- **볼륨을 0으로 해도 잔향이 들림 (12.24에서 생긴 문제)**
  - 공간 잔향으로 가는 경로가 채널 볼륨을 거치지 않고 바로 출력으로 갔습니다.
  - 이제 총소리·장비음·명중음·발소리 잔향이 각각 해당 볼륨을 따르고, 볼륨 0이면 잔향도 들리지 않습니다.
- **칼이 벽 모서리 뒤 표적을 맞힘 (12.21에서 생긴 문제)**
  - 휘두르기 판정 범위 안에 있는 표적을 고를 때, 화면 중앙 광선에 걸린 벽만 확인하고 표적까지의 경로는 확인하지 않았습니다.
  - 이제 표적까지 막힘이 없어야 맞습니다. 새 규칙(v6)에만 적용되며, 이전 리플레이는 녹화 당시 판정 그대로 재생됩니다.

## 검증

- 애플리케이션·hosting·broker 테스트 전부 통과, 타입 검사와 전체 빌드 검증(`pnpm build`) 통과
- 새 테스트
  - 12.26에서 녹화한 코스 리플레이 검증
  - 채널별 잔향 경로와 볼륨
  - 벽 모서리 뒤 표적, 이전 규칙의 판정 유지, 시야가 트인 표적
