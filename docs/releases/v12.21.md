# VALOPRAC 12.21 — 칼 슬롯과 무기 전환 수정
2026년 11월 26일 · 기능 패치

숫자 키가 1 주무기 · 2 보조무기 · 3 칼로 고정되고, 근접 무기인 칼이 추가됐습니다. 이동하면서 무기를 바꾸면 캐릭터가 멈추던 문제도 고쳤습니다.

## 수정

- **무기 전환 시 멈춤 수정**: W 같은 이동 키를 누른 채 숫자 키로 무기를 바꾸면, 키를 계속 누르고 있어도 캐릭터가 멈췄습니다. 무기를 바꿀 때 눌려 있던 키 정보를 모두 지웠는데, 브라우저는 새 키가 눌리면 이전 키의 자동 반복을 멈추기 때문이었습니다. 이제 무기를 바꿀 때는 사격·조준 입력만 놓고 이동 키는 유지합니다.

## 변경 사항

- **고정 무기 슬롯**: `1` 주무기, `2` 보조무기(셰리프), `3` 칼. 주무기는 무기 화면에서 마지막으로 고른 밴달·팬텀·오퍼레이터를 꺼냅니다. 기존의 `4` 키(오퍼레이터)는 1번 슬롯으로 합쳐졌습니다.
- **칼**: 좌클릭은 베기(피해 50, 사거리 2.2m, 0.5초마다), 우클릭은 찌르기(피해 75, 사거리 1.9m, 0.95초마다)입니다. 누르고 있으면 계속 공격합니다. 체력 150의 표적은 베기 3번 또는 찌르기 2번에 쓰러집니다. 자유 연습의 "아무 부위나 맞으면 처치" 규칙도 그대로 적용됩니다.
- **칼을 들면 더 빠르게**: 이동 속도가 6.75m/초로 올라가고, 정조준은 하지 않습니다.
- **칼 디자인 6종**: 무기 화면의 "칼" 영역에서 고를 수 있습니다. 모두 직접 만든 3D 모델이며, 게임 분위기에 맞춰 짙은 회색과 청록 강조색을 썼습니다.
  - 실제형: 필드 나이프, 탄토, 카람빗, 쿠나이
  - 판타지: 에테르 블레이드(떠 있는 청록 에너지 날), 흑요석 송곳니(용암 균열이 빛나는 흑요석)
- 칼은 화면 오른쪽 아래에 들고 있어서 조준점을 가리지 않습니다. 베기는 화면 아래쪽을 가로지르고, 찌르기는 앞으로 곧게 나갑니다.
- 칼 소리(휘두르기, 찌르기, 명중, 벽 충돌, 꺼내기)는 모두 직접 합성한 소리입니다.
- HUD 오른쪽 아래에 1·2·3 슬롯 표시줄이 생겼습니다. 칼을 들면 탄약 대신 공격 방법이 표시됩니다.

## 기록·리플레이

- 칼 공격은 사격 통계(명중률, 반동, 제동 분석)에 들어가지 않습니다. 처치는 기존처럼 처치 기록에 남습니다.
- 리플레이 파일 형식은 바뀌지 않았습니다. 이전 리플레이는 그대로 재생·검증되고, 칼을 쓴 새 리플레이도 기록·재생·검증됩니다.

## 검증

- 애플리케이션 테스트 1,533개, broker 테스트 28개, hosting 테스트 30개 통과, 타입 검사 통과
- 새 테스트: 이동 키를 누른 채 무기를 바꿔도 이동이 유지되는지, 슬롯 배치, 칼 사거리·피해·회복 시간, 칼을 들었을 때의 이동 속도, 칼 처치가 포함된 리플레이의 기록·검증·재생
- 칼 6종과 베기·찌르기 동작은 브라우저 소프트웨어 렌더링(SwiftShader) 화면으로 확인했습니다.
