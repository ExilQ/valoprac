# VALOPRAC 12.23 — 그래픽 품질 단계 정리와 최고 품질 성능 개선
2026년 11월 26일 · 그래픽 패치

고사양 PC에서도 최고 품질로 올리면 프레임이 크게 떨어지고 끊기던 문제를 다뤘습니다. 최고 품질이 높음과 같은 방식으로 가볍게 그려지도록 바꾸고, 품질 단계를 다른 FPS 게임처럼 정리했습니다. 내 컴퓨터에서 직접 측정해 알맞은 품질을 추천받을 수도 있습니다.

## 원인

12.22의 최고 품질만 일반 렌더링 방식을 벗어나 있었습니다.

- 장면을 화면이 아닌 별도의 고정밀(HDR) 4× 멀티샘플 버퍼에 그린 뒤, 화면 전체 후처리를 다섯 번 더 거쳤습니다.
- 주변광 차폐(SSAO)가 장면을 **두 번 더** 그렸고, 결과를 절반 해상도 이미지로 덮어써서 화면이 오히려 흐려졌습니다.
- 시작할 때 빛 번짐이나 주변광 차폐가 켜져 있으면 화면 자체가 안티에일리어싱 없이 만들어져, 나중에 꺼도 그 훈련 동안 무거운 경로가 계속 쓰였습니다.

## 변경 사항

- **모든 품질 단계가 장면을 한 번만 그려 화면에 바로 출력합니다.** 최고 품질은 더 이상 빛 번짐과 주변광 차폐를 켜지 않습니다.

  | | 낮음 | 보통 | 높음 | 최고 |
  |---|---|---|---|---|
  | 렌더링 배율 | 80% | 100% | 100% | 100% |
  | 안티에일리어싱 | 끄기 | MSAA | MSAA | MSAA |
  | 그림자 | 끄기 | 1024² | 2048² | 2048² |
  | 재질 해상도 | 32px | 64px | 256px · 노멀 | 256px · 노멀 |
  | 텍스처 필터링 | 1× | 2× | 8× | 16× |
  | 탄흔·파편 | 12개 | 24개 | 48개 | 96개 |
  | 빛 번짐 · 주변광 차폐 | 선택 | 선택 | 선택 | 선택 |

  VALORANT·CS2처럼 단계는 그림자, 재질과 필터링, 안티에일리어싱으로 나누고, 빛 번짐·주변광 차폐는 따로 켜는 선택 사항으로 두었습니다.
- **주변광 차폐(선택)** 는 GTAO 방식으로 바꿨습니다. 절반 해상도로 계산한 그림자를 원래 해상도 화면 위에 얹어, 켜도 화면이 흐려지지 않습니다.
- **안티에일리어싱** 은 이제 그 설정 하나만 따릅니다. 빛 번짐·주변광 차폐 설정 때문에 무거운 경로에 갇히지 않습니다.
- 기존 12.21·12.22 품질 단계를 그대로 쓰던 설정은 처음 실행할 때 새 단계로 한 번 옮겨집니다. 직접 바꾼 설정은 유지됩니다.

## 설정 → 그래픽

- **품질 단계 표**: 단계마다 무엇이 바뀌는지 보여 주고, 지금 단계(또는 사용자 지정)를 표시합니다.
- **그래픽 실행 환경**: 브라우저가 실제로 쓰는 그래픽 장치 이름, 하드웨어 가속 여부, 실제 렌더링 해상도를 보여 줍니다. 브라우저가 그래픽카드 대신 CPU로 그리고 있으면 눈에 띄게 경고하고 켜는 방법을 안내합니다. 고사양 PC에서 웹 게임이 한 자릿수 프레임으로 떨어지는 가장 흔한 원인입니다.
- **내 컴퓨터로 측정**: 약 10초 동안 지금 화면 크기로 네 단계를 직접 그려 보고, 모니터 주사율을 유지하는 가장 높은 품질을 추천합니다. 결과는 이 브라우저에만 저장됩니다.

## 측정 결과

소프트웨어 렌더러(SwiftShader)에서 같은 조건으로 비교한 값입니다. 실제 그래픽카드에서는 절대값이 훨씬 빠르며, 상대 비교로만 봐야 합니다.

- 실제 훈련 세션(이동·회전·사격 10초): 최고 품질 프레임 시간 중앙값 **103.3밀리초 → 63.9밀리초 (약 38% 감소, 초당 9.7 → 15.6프레임)**. 높음과 거의 같아졌습니다.
- 한 프레임에 그리는 횟수: 최고 품질 162회 → 79회, 삼각형 81,453개 → 42,002개, 화면 전체 후처리 5회 → 0회.

## 검증

- 애플리케이션 테스트 1,544개, broker 테스트 28개, hosting 테스트 30개 통과, 타입 검사·릴리스 검증·번들 빌드 통과.
- 새 테스트: 모든 단계가 후처리 없이 그려지는지, 단계별 그림자·재질·필터링 순서, 12.21·12.22 설정의 한 번만 옮겨지는 이전, 측정 결과에서 품질을 고르는 규칙, 주변광 차폐 패스의 자원 해제.
- 확인하지 못한 항목: **실제 그래픽카드에서의 프레임** (이 환경에는 그래픽카드가 없습니다), Safari·Firefox. 설정 → 그래픽 → "내 컴퓨터로 측정" 결과를 알려 주시면 다음 패치에 반영하겠습니다.
