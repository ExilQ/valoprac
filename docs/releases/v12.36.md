# VALOPRAC 12.36 — 발로란트 공식 값 기준 전체 물리 검증

VALOPRAC의 물리 매개변수를 모두 목록으로 만들고, 공식 위키와 Riot이 공개한 수치에 하나씩 대조했습니다. 공개 자료로 확인되는 값은 모두 일치시켰습니다. 공개 자료가 없는 값은 "보정값"으로 표시했습니다. 항목별 대조표는 [발로란트 기준 전체 물리 검증 보고서](https://github.com/ExilQ/valoprac/blob/v12.36/docs/VALORANT_REFERENCE_12.36.md)에 있습니다.

**이전과 달랐던 점**
- **앉기 배율**: 밴달 0.72, 팬텀 0.68, 오퍼레이터 0.85였습니다.
- **최대 퍼짐**: 밴달 1.5°, 팬텀 1.3°, 셰리프 3.45°였습니다.
- **이동 오차**: 첫 발 오차를 포함한 총량이었고, 정조준 중에는 줄여서 적용했습니다.
- **오퍼레이터 비조준 이동 오차**: 최대 +5°였습니다.
- **연사 퍼짐**: 연사 중에도 회복돼 거의 커지지 않았습니다. 이제 밴달은 7발째, 팬텀은 8발째에 공식 최대값에 도달합니다.

## 정확도 상태 규칙

- **데드존**: 무기 달리기 속도의 27.5% 이하로 움직이면 이동 오차가 없습니다(3.0 패치). 이전에는 12%(0.65m/s)였습니다.
- **걷기 정확도**: 61%까지는 걷기 오차, 그보다 빠르면 달리기 오차입니다(Riot 개발자 공개 수치).
- **멈추는 중**: 달리다 멈추는 동안에는 걷기 단계를 거치지 않고, 데드존까지 달리기 오차가 유지됩니다(0.50 패치).
- **착지 직후**: 0.225초 동안 모든 무기에 +7°가 붙습니다(1.09 패치). 이전에는 오퍼레이터를 빼면 +0.35°, 0.09초였습니다.

## 칼

등 뒤를 공격하면 피해가 2배(100/150)입니다(공식 위키).

## 다른 물리 엔진

- **카운터 스트라이크 엔진(설정의 CS2 물리)**: CS2 서버 기본값과 다른 네 가지를 맞췄습니다. 점프 높이는 CS2와 같은 1.448m입니다.

  |---|---|---|
  | 점프 속도 | 7.4m/s | 7.67m/s |

  | 정지 기준 속도 | 2.0m/s | 2.032m/s |
  | 계단 높이 | 0.3m | 0.457m |

- **Unreal 포팅용 C++ 코어**: 같은 모델(감속, 반대키 정지, 데드존, 연사 퍼짐, 공식 퍼짐 표)을 옮겼습니다. 30·60·144·240fps에서 브라우저 시뮬레이션과 소수점 10자리까지 일치합니다.

## 공식 값과 일치한 그대로인 항목

달리기 속도(5.4·5.13·6.75m/s), 정조준 이동(76%·72%), 연사 속도, 탄창·예비 탄약, 재장전, 장착 시간, 부위별 피해와 거리 감소, 관통 등급, 칼 피해, 팬텀 소음기 40m는 이미 공식 값과 같았습니다.

## 공식 값이 없어 보정값으로 남은 항목

- 걷기 48%, 앉아 이동 36%, 뒤로 이동 92%
- 연사 퍼짐 증가량과 회복 속도, 반동 패턴
- 발소리 기준 속도와 간격, 칼 사거리
- 점프 높이·체공: 리플레이 실측과 1.3% 차이
- 가속: 추정치(0.258초)에 맞춤
- 피격 감속(태깅) 72.5%: 지속 시간이 공개되지 않아 미반영

공식 페이지 일부(팬 위키, Liquipedia, Riot 개발자 글 모음)는 이 환경의 네트워크 설정에서 막혀 검색 요약으로만 확인했습니다.

## 기존 리플레이 호환

새 동작은 새 시뮬레이션 규칙(`reference-v11`, 리플레이 시뮬레이션 11)에만 적용됩니다. 이전 리플레이는 녹화 당시 규칙으로 그대로 재생·검증됩니다.
