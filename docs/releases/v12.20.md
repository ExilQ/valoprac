# VALOPRAC 12.20 — 인터페이스 디자인 개선
2026년 11월 26일 · 디자인 패치

메뉴 화면(훈련·맵·무기·감도 실험실·기록·설정)과 일시정지 카드의 디자인을 정리했습니다. 게임플레이, HUD 배치, 시뮬레이션, 저장 데이터, 주소는 바뀌지 않았습니다.

## 변경 사항

- **강조색 하나로 통일**: "훈련 시작"에 따로 쓰이던 주황색을 없앴습니다. 주요 버튼과 현재 선택 항목은 이제 같은 청록색 하나로 표시됩니다.
- **새 다크 테마**: 청록빛이 돌던 회색을 중립 그래파이트 톤으로 바꿨습니다. 위로 올라온 표면일수록 밝아지고, 구분선은 더 부드러워졌습니다. 라이트 테마는 그대로입니다.
- **훈련 브리핑이 테마를 따름**: 라이트 테마에서도 어두운 판으로 고정돼 있던 브리핑이 이제 현재 테마에 맞춰 표시됩니다. 사선 모서리와 해치 무늬는 유지했습니다.
- **버튼 위계 수정**: `.primary-button`이 보조 버튼과 똑같이 보이던 문제를 고쳤습니다. 예를 들어 감도 실험실의 "첫 기준 평가 시작" 버튼이 다시 강조됩니다.
- **페이지 틀 통일**: 페이지마다 달랐던 제목 위치, 여백, 제목 크기를 맞췄습니다. 제목 아래에 생기던 밑줄을 없애고, 맵 미리보기 카드와 기록 차트에 여백을 넣었습니다.
- **상단 바**: 언어 선택에 보이던 영어 "Language" 글자를 지구본 아이콘으로 바꿨습니다. 화면 낭독기에는 계속 이름이 전달됩니다.
- **한국어 줄바꿈**: 본문 단어가 중간에서 끊기지 않도록 했고, 숫자는 같은 폭으로 표시합니다. 동작 줄이기와 고대비 모드에서는 대체 스타일이 적용됩니다.

## 검증

- 애플리케이션 테스트 1,526개, broker 테스트 28개, hosting 테스트 30개 통과, 타입 검사 통과
- 두 테마 모두 WCAG 색 대비 검사 통과
- 확인하지 못한 항목: 실제 GPU 렌더링, Safari/Firefox, 실제 사용성. 전체 `pnpm build` 검증은 Git에 없는 QA 비교 이미지가 필요해서 새 체크아웃에서는 `verify-build` 단계에서 멈춥니다. 이 문제는 12.20 이전부터 있었습니다.
