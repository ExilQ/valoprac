# VALOPRAC 12.30 — 44.1kHz 오디오 장치의 맵 잔향 복구
2026년 11월 26일 · 사운드 수정

PR 자동 코드 리뷰(Codex)가 지적한 문제를 확인해 고쳤습니다.

## 문제 (12.24에서 생긴 문제)

- 맵별 공간 잔향(콘볼루션 리버브)의 임펄스 응답을, 훈련 시작 전에 별도 스레드에서 48kHz로 미리 만들어 둡니다.
- Web Audio 규격상 잔향 장치(ConvolverNode)는 오디오 장치와 샘플레이트가 같은 응답만 받습니다.
- 그래서 44.1kHz로 동작하는 오디오 장치에서는 응답이 거부됐고, 이 오류가 조용히 처리돼 **잔향 없이** 소리가 났습니다. 44.1kHz 장치는 Windows PC에서 흔합니다.

## 수정

- 미리 만든 응답의 샘플레이트가 오디오 장치와 다르면, 장치의 샘플레이트로 다시 만들어 넣습니다.
- 총소리, 발소리 같은 일반 효과음은 브라우저가 재생할 때 자동으로 변환하므로 영향이 없었습니다.

## 검증

- 48kHz로 미리 만든 응답을 다른 샘플레이트 장치에 넣는 테스트 추가. 수정 전에는 실패하고 수정 후에는 통과하는 것을 확인했습니다.
