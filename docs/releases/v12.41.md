# VALOPRAC 12.41 — 썸띵 무빙 수정
2026년 11월 28일 · 봇 무빙 패치

썸띵 스타일 봇 무빙을 알려주신 설명대로 다시 만들었습니다: "브레이킹 대충 걸고 한 발 쏜 다음 와이드를 긁고 쏘는 무빙".

## 동작

1. 짧게 피킹합니다(0.14~0.2초).
2. 데드존까지만 대충 브레이킹하고 한 발을 쏩니다. 한 발로 제한합니다.
3. 멈추지 않고 같은 방향으로 와이드를 긁습니다(0.42~0.58초).
4. 완전히 멈춰서 쏩니다.
5. 반대쪽에서 다시 반복합니다.

## 측정

- 피킹이 끝날 때 3.9~4.4m/s에서 브레이킹해, 1.35m/s(데드존 1.485m/s 아래)에서 한 발을 쏩니다.
- 그 뒤 같은 방향으로 5.4m/s로 와이드를 긁습니다.
- 쏘지 못한 경우에는 데드존 아래에 0.07초 머문 뒤 와이드로 넘어갑니다.

## 케인제라 무빙

케인제라(canezerra, 전 RANKERS·ENVY, 현 Sentinels) 선수의 무빙을 분석한 공개 자료를 찾지 못해, 이번에는 넣지 않았습니다. 무빙 설명을 받으면 추가합니다.

## 검증

- 애플리케이션 테스트, hosting 테스트, broker 테스트 전부 통과
- 타입 검사, 전체 빌드 검증 체인(`pnpm build`) 통과
- 새 테스트: 피킹과 와이드가 같은 방향인지, 와이드가 피킹보다 긴지, 다음 동작은 반대쪽에서 시작하는지, 탭이 완전히 멈추기 전(데드존 아래)에 한 발로 나가는지
