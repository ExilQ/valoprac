# VALOPRAC 12.29 — Cloudflare 배포 보안 수정
2026년 11월 26일 · 보안 수정

PR 자동 코드 리뷰(Codex)가 보안 문제를 하나 지적했습니다. 확인 결과 실제 문제였고, 고쳤습니다.

## 문제

12.26에서 만든 Cloudflare 배포 진입점(`worker/cloudflare.js`)은 GPU 스트리밍 허가 API(`/api/gpu/grant`)를 그대로 연결하고 있었습니다.

- 이 API는 사용자 식별 헤더(`oai-authenticated-user-id`)를 신원으로 믿습니다. 이 헤더는 ChatGPT Sites가 직접 붙이고 덮어쓰기 때문에 그곳에서는 안전합니다.
- Cloudflare에서는 누구나 이 헤더를 붙여 보낼 수 있습니다. 그래서 GPU 허가 비밀값과 허용 목록이 설정돼 있다면, 위조한 헤더로 허가 토큰을 받을 수 있었습니다.

## 수정

- Cloudflare 진입점에서는 GPU 허가 API를 제공하지 않습니다. 위조한 헤더로 요청해도 404가 나옵니다.
- 사용량 API는 Cloudflare가 직접 붙이는 접속 주소 헤더만 쓰므로 그대로 둡니다.

## 영향

- 현재 사이트(ChatGPT Sites 배포)는 바뀌지 않았고, 이 문제의 영향도 없습니다.
- Cloudflare 배포는 아직 운영 중이 아니어서 실제로 노출된 적이 없습니다.

## 검증

- hosting 테스트에 위조 헤더 요청 테스트 추가(404, 토큰 없음)
- 애플리케이션·hosting·broker 테스트, 타입 검사, 전체 빌드 검증 통과
