# VALOPRAC 12.26 — 전체 점검과 품질 수정
2026년 11월 26일 · 점검 패치

사이트, 게임, 디자인, 사운드, 화면을 처음부터 끝까지 다시 점검했습니다. 확인된 문제는 고쳤고, 고치지 않은 항목은 이유와 함께 아래에 적었습니다. 전체 결과는 [점검 보고서](https://github.com/ExilQ/valoprac/blob/v12.26/docs/AUDIT_12.26.md)에 있습니다.

## 고친 문제

- **영어 화면 번역 누락**: 12.21~12.25에서 추가한 칼, 그래픽 설정, 성능 측정, 기본기 맵 문구 약 130개가 영어 번역에 빠져 있었습니다. 그래서 "주Weapon", "Angles 체크"처럼 한국어와 영어가 섞여 보였습니다. 이제 영어 화면에 남는 한국어가 없고, 이를 확인하는 테스트도 추가했습니다.
- **칼 소리가 너무 큼**: 칼을 휘두르는 소리가 밴달 사격음과 거의 같은 크기였습니다. 이제 사격음보다 약 8dB 작습니다. 칼 꺼내는 소리도 다른 무기의 장착음과 같은 크기로 맞췄습니다.
- **발소리·총소리 변형 간 음량 차이**: 같은 바닥에서 나는 발소리 네 가지가 서로 최대 4.1dB 달랐습니다. 지금은 0.2dB 이내입니다. 연사할 때 번갈아 나는 총소리 변형의 음량 차이도 최대 2.5dB에서 1.7dB로 줄었습니다. 남은 차이는 반복감을 줄이려고 일부러 둔 ±0.7dB 변화가 대부분입니다.
- **접근성**
  - 휴대폰에서 가로로 스크롤되는 안내 표를 키보드로도 움직일 수 있습니다.
  - 측정 방법 안내 페이지에 본문 영역을 지정하고, 중복된 바닥글을 하나로 합쳤습니다.
  - 일부 화면 요소의 잘못된 역할 지정을 고쳤습니다.
- **Cloudflare 배포 설정**: 사이트를 Cloudflare로 옮길 때 쓸 설정에 두 가지 문제가 있었습니다.
  - 보안 정책이 모든 페이지의 테마 스크립트를 막았습니다.
  - 없는 주소가 404 대신 첫 화면을 보여 줬습니다.

  이제 워커가 페이지마다 실제 스크립트 해시로 보안 정책을 만들고, 없는 주소에는 404를 돌려줍니다. 현재 ChatGPT Sites 배포와 같은 응답 규칙입니다.
- **전체 빌드 검증**: 검증 스크립트가 이미지와 설정 파일이 저장소에 없어서 중간에 멈췄습니다. 이미지 43개는 실제 사이트에서 받았고, 기록된 해시와 일치하는 것을 확인한 뒤 복구했습니다. 이제 전체 빌드 검증이 끝까지 통과합니다.

## 점검 결과 정상인 항목

- 사이트 21개 페이지를 화면 크기 3종(1920·1366·390px)과 밝은/어두운 테마로 열었습니다.
  - 콘솔 오류, 실패한 요청, 가로 넘침, 색 대비 위반이 없었습니다.
  - Cloudflare 설정으로 서빙했을 때 깨진 링크가 없었습니다.
- 게임 수치
  - 감도 0.35·800DPI에서 360도 회전 거리는 46.65cm로, 발로란트 계산식과 같습니다.
  - 밴달 연사 속도, 탄창, 재장전, 부위별 피해가 공개 수치와 같습니다.
  - 팬텀 거리별 피해는 9.10 패치의 2단계 구조(20m)와 같습니다.
  - 달리기 속도는 5.4m/s, 칼은 6.75m/s입니다.
  - 연사 반동으로 올라간 화면은 1초 안에 제자리로 돌아옵니다.
- 실제 빌드 브라우저 플레이에서 다음을 확인했습니다.
  - 이동 중 무기를 바꿔도 멈추지 않습니다.
  - 칼을 들면 6.75m/s로 달립니다.
  - 재장전과 일시정지가 정상입니다.
- 소리 93개에 클리핑, 직류 성분, 시작·끝 딸깍임이 없습니다.

## 고치지 않은 항목 (판단 필요)

- **실제 사이트가 12.22입니다.** 12.23~12.26은 GitHub 릴리스에만 있고, `production`에 합쳐 배포해야 사이트에 반영됩니다.
- **맵 이름**: 맵별 전술 훈련 코스 12개가 발로란트 맵 이름(스플릿, 바인드, 헤이븐 등)을 쓰고 있습니다. 배치는 VALOPRAC이 직접 만들었지만, 이름 사용은 Riot 팬 콘텐츠 정책 범위 안에서 판단이 필요합니다.
- **예비 탄약**: 밴달 75발, 팬텀 90발로 설정돼 있습니다. 발로란트는 6.11 패치부터 50발, 60발입니다. 기본값인 "예비 탄약 무제한"을 끌 때만 차이가 납니다. 고치면 기존 리플레이의 보정값 지문이 바뀌므로 따로 결정이 필요합니다.
- **팬텀 이동 중 탄 퍼짐**: 6으로 설정돼 있지만 9.10 패치 노트에는 6.5로 올렸다고 나옵니다. 이후 패치에서 바뀌었는지 확인하지 못해 그대로 뒀습니다.
