## Implemented behavior and changed algorithms

The opt-in movement tools extend the existing maps, manual controls and selected VALORANT/Counter-Strike movement profile. They do not introduce an automatic jump, automatic air strafe or a replacement movement arena. Tools default to disabled; configurable, conflict-checked letter bindings are **K save, L restore, T last takeoff and Y reset current attempt**. Paused buttons expose the same four explicit commands.

A bookmark captures actual position, yaw/pitch, velocity, crouch, grounded/airborne state, map, physics version and airborne takeoff budget. Restore validates map/profile compatibility, finite values, bounds, standing/crouched body clearance, ceiling and floor/ramp support. An airborne restore retains its original velocity and speed budget and cannot create another jump. Explicit restore clears pending input, jump-chain timing and stale render/fire, braking and sound trackers; it does not grant jump/landing events, erase training statistics or reset defender health. Failure leaves the player in place and displays a reason.

Each actual takeoff captures a separate attempt origin. **Y now returns to the latest physical attempt, while L preserves the independently saved bookmark**; this fixes the earlier integration behavior that could reset to an older saved point. The recorded clip begins at the last grounded boundary, preserving the first vertical displacement. Resolved120Hz motion supplies takeoff/landing positions, maximum height and speed, horizontal distance, duration and speed preservation. Only display samples are reduced to approximately30Hz, with a600-point/20-second bound. The paused panel shows actual metrics and a speed graph; optional world-space lines show the resolved path.

Ghosts are a bounded display cache derived by re-executing the **common A2 ReplayPlayer**, including the same movement-tool command stream and integrity checkpoints. There is no independent ghost recorder or physics model. Each clip is at most20seconds/600display samples and supports cancellation; partial-prefix reconstruction explicitly differs from final outcome verification. Runtime reconstruction additionally limits the candidate prefix to120,000commands. A long or unavailable candidate produces an explanation instead of unbounded work. Live player state and RNG streams remain separate. The translucent marker/path has no collision, hitboxes, target registration or shadows.

**Ghost display time restarts on a successful restore and every fresh physical jump**, fixing the earlier case where a second attempt could leave the marker at the old path's endpoint. The active attempt's start time anchors display interpolation. The paused interface now calls the tested `compareMovementGhost` helper and displays signed elapsed-time, horizontal-distance, peak-speed and peak-height deltas plus unsigned landing separation. Speed preservation is compared in percentage points only when both attempts have valid single-landing measurements. The sign convention is explicitly current attempt minus previous ghost. An active attempt is labeled incomplete; unavailable landing/preservation values display an em dash rather than invented zeroes. GameStage reads the existing Runtime ghost getter during normal telemetry renders; this adds no Runtime creation, restart or effect dependency.

Camera review uses the same ReplayViewer with first-person, top-down and **third-person inspection**. The third-person boom follows recorded yaw, shortens before actual walls/ceilings and shows a display-only stance marker. It never changes authoritative movement, collision or shot registration. Review rendering disables submitted-frame recording so inspecting a camera cannot alter replay authority. Escape explicitly releases Pointer Lock and buffered movement instead of relying solely on browser defaults.
