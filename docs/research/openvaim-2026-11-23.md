# openVaim 코드 분석과 VALOPRAC 적용

2026-11-23 기준으로 openVaim의 `8ae65d97054ee425b41cbf6b90b75bc9ebe02882` 커밋과 VALOPRAC 12.0.14를 비교했다.

## Studio와 게임 런타임

openVaim은 Electron에서 로컬 웹 서버를 열고 기존 게임 파일 위에 자체 시나리오와 UI를 얹는다. Studio는 편집한 배치의 좌표와 트리거를 게임 문서로 컴파일한다. 게임이 그 문서를 실행하므로 편집기에서 만든 과제도 로비 과제처럼 저장·재생된다. 이 구조에서 가져올 부분은 편집·미리보기·실행 사이에 하나의 시나리오 정의를 공유하는 방식이다. VALOPRAC은 기존 `ScenarioDefinition`을 확장해 보라색 미리보기 경로, 브라우저 전투에서 쓰는 경로, 공유 코드가 같은 자료를 사용하게 했다. [아키텍처](https://github.com/unkwsr/open-aim/blob/8ae65d97054ee425b41cbf6b90b75bc9ebe02882/docs/architecture.md) · [시나리오 형식](https://github.com/unkwsr/open-aim/blob/8ae65d97054ee425b41cbf6b90b75bc9ebe02882/docs/scenario-format.md)

## Copycat과 사후 복기

openVaim Copycat은 수비수 위치에서 별도 기록 라운드를 열고, 실제 위치·자세·사격·공중 상태를 상대 좌표로 저장한다. 반복 재생과 시작 지점, 구간 자르기, 반전, 사격 시점 등을 설계자가 조절한다. Studio의 3D 보기에서도 기록된 앉기와 높이를 읽어 캐릭터를 표시한다. 이 기능의 훈련 가치는 사람의 타이밍이 담긴 움직임을 다시 조준해 볼 수 있다는 점이다. VALOPRAC은 같은 맵의 기존 리플레이에서 짧은 지면 이동 구간을 추출한다. 저장한 기록 하나를 복기하고 다시 훈련 재료로 쓰는 흐름에 맞춘 선택이다. [Copycat 컴파일러](https://github.com/unkwsr/open-aim/blob/8ae65d97054ee425b41cbf6b90b75bc9ebe02882/app/studio/drill.js#L615) · [3D 자세 재생](https://github.com/unkwsr/open-aim/blob/8ae65d97054ee425b41cbf6b90b75bc9ebe02882/app/studio/view3d.js#L619)

openVaim의 라운드 타임라인은 약 9.8Hz로 위치를 샘플링하고 사격·킬을 별도 기록한다. 미리 할당한 배열을 써 기록 비용을 제한하고 라운드가 끝나면 필요한 범위만 전달한다. VALOPRAC은 기존 120Hz 입력 리플레이를 다시 실행한 다음 10Hz 상대 위치와 앉기 비율만 따로 보관한다. 분석은 편집 화면에서 시작한다. 내보내는 시나리오에는 1–4초의 상대 좌표와 자세가 포함된다. 수비수의 조준·발사 조건은 실제 플레이 중 시야와 기존 무기 규칙으로 계산한다. [라운드 타임라인](https://github.com/unkwsr/open-aim/blob/8ae65d97054ee425b41cbf6b90b75bc9ebe02882/app/site/local/round-timeline.mjs)

## 무작위성, 비교, 공유

openVaim은 동일 훈련에서도 시드나 시작 시 섞기 규칙에 따라 다른 수비 배치를 낸다. 같은 조건의 개인 성과를 판단할 때는 배치와 난이도 변화가 결과에 섞일 수 있다. VALOPRAC은 시드와 초기 배치를 고정한 상태에서 수비수 경로만 제거한 고정판을 제공한다. 최근 기록은 경로, 무기, 물리·감도 설정과 수비수 정책이 맞는 경우에 집계한다. 지표는 각 클리어·사망·첫 발 헤드샷이며 기록 수를 함께 표시한다. [드릴 섞기](https://github.com/unkwsr/open-aim/blob/8ae65d97054ee425b41cbf6b90b75bc9ebe02882/app/drill-shuffle.js) · [기록 보드](https://github.com/unkwsr/open-aim/blob/8ae65d97054ee425b41cbf6b90b75bc9ebe02882/app/site/aim-ui/history-board.mjs)

openVaim Workshop은 공유 코드와 게시·검토·순위 기능을 연결한다. VALOPRAC에서는 기존 브라우저 보관함과 공유 코드를 사용한다. 내보낸 자료를 받는 쪽에서도 맵·시드·초기 배치와 이동 표본을 다시 확인한다. 원본 플레이 기록, 계정과 순위는 공유 payload의 범위 밖이다. [Workshop 코드](https://github.com/unkwsr/open-aim/blob/8ae65d97054ee425b41cbf6b90b75bc9ebe02882/app/community-workshop.js) · [라이선스](https://github.com/unkwsr/open-aim/blob/8ae65d97054ee425b41cbf6b90b75bc9ebe02882/LICENSE)

## 이번 배포 범위

- 전술 경로 탭에서 차고 문틀 예제의 이동 재현을 체험할 수 있다. 예제는 설계한 경로다.
- 시나리오 편집기에서 같은 맵의 최근 리플레이를 고르고, 시작 시점과 길이를 정한 뒤 선택한 수비수에게 연결한다. 2D와 3D에서 경로와 머리 높이를 확인하고, 회전과 좌우 반전으로 배치를 맞춘다.
- 시작 지점부터 바닥·벽·경계·천장을 고정 연산 간격으로 검사한다. 추출 대상은 지면에 붙은 이동과 앉기다. 착지하거나 높이가 급격히 바뀌는 구간은 지형 검증에서 제외될 수 있다.
- 훈련 결과 화면에서 같은 배치의 고정·이동 조건을 오가고, 각각 최대 다섯 기록을 확인한다.
