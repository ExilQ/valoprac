## 3. 정상으로 확인한 항목

- **빌드·테스트**
  - 애플리케이션 테스트 1,564개, hosting 테스트 36개, broker 테스트 28개 통과
  - 타입 검사, 릴리스·검색·modern-web·응답 워커 검증 통과
- **화면**
  - 21개 페이지 × 3개 화면 크기 × 2개 테마에서 콘솔 오류, 페이지 오류, 실패한 요청이 없었습니다.
  - 가로 넘침이 없었고, axe 색 대비 위반도 없었습니다(테마 대비 검증 스크립트도 통과).
- **사이트(운영)**
  - HTTPS, HSTS, CSP(인라인 스크립트 해시), X-Frame-Options, nosniff가 적용돼 있습니다.
  - 없는 문서는 404이고, robots.txt는 학습용 크롤러를 차단합니다.
  - sitemap에는 홈만 있으며, 홈만 색인을 허용하는 정책과 일치합니다.
- **게임**
  - 감도: 0.35·800DPI에서 360도 회전 거리는 46.65cm로, 회전량 0.07도/카운트인 발로란트 계산식과 같습니다.
  - 밴달: 연사 25발에 2.475초(9.7발/초), 탄창 25발, 재장전 2.5초, 피해 160/40/34
  - 팬텀: 20m 기준 2단계 피해(156→140)로 9.10 패치와 같습니다.
  - 셰리프·오퍼레이터의 연사 속도, 탄창, 재장전, 피해가 공개 수치와 같습니다.
  - 달리기 5.4m/s, 칼 6.75m/s
  - 카메라 반동은 밴달 25발 기준 최대 6.3도 올라가고, 1초 뒤 0.02도 이내로 돌아옵니다.
  - 실제 빌드 자동 플레이
    - W를 누른 채 2·3·1번으로 무기를 바꿔도 속도 5.4m/s가 유지됐습니다(칼은 6.75).
    - 탄약 소모와 재장전 1.1초 표시, Esc 일시정지가 정상이었습니다.
    - 클릭 길이에 맞게 발사됐습니다(누름 시간 128·77·300ms → 2·1·3발).
- **사운드**: 93개 모두 피크 0.97 이하이고, 직류 성분은 1e-3 미만, 시작·끝 샘플은 0입니다.
