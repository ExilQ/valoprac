훈련장설정물리·재질 검증

12.01 · 사용성과 웹 표준

필요한 화면부터, 훈련은 빠르게.

기존 훈련 기능과 밝은 화면을 유지하며, 훈련 선택·미리보기·키보드 탐색·기록 관리를 개선했습니다. 물리·사격·리플레이의 호환 규칙은 12.00과 같습니다.

화면에 맞는 훈련 배치

전체 화면 크기뿐 아니라 패널에 실제로 주어진 너비에 따라 설정과 맵 정보를 나란히 또는 위아래로 배치합니다. 훈련 종류는 이전처럼 접을 수 있습니다.

선택할 때 켜는 3D 미리보기

처음에는 실제 충돌·경로 정보로 그린 평면도를 보여 줍니다. 3D 미리보기를 켜거나 훈련을 시작할 때 그래픽 코드를 불러옵니다. 설정·무기·기록 화면도 필요할 때 불러옵니다.

브라우저와 함께 쓰는 메뉴

메뉴에 실제 주소를 연결해 새 탭 열기와 뒤로 가기를 지원합니다. 본문 바로가기, 화면 전환 뒤 초점, 각 화면의 제목과 선택 상태도 제공합니다.

명확한 기록 삭제

삭제 확인창의 기본 선택은 취소입니다. 키보드로 두 동작을 고르고 Esc로 닫을 수 있습니다. 실제 저장소에서 삭제에 성공한 뒤 목록을 갱신합니다.

같은 해상도에서 비교

1366 × 768 브라우저의 전체 페이지 캡처입니다. 같은 자유 훈련장·밝은 테마에서 촬영했으며 실제 화면을 재구성하거나 합성하지 않았습니다. WebP로 압축했고, 전체 페이지 길이는 화면 배치에 따라 다릅니다.

검증과 범위

자동 테스트·화면·탐색 검증 결과 · 적용한 구글 크롬 웹 지침

브라우저 검증은 소프트웨어 그래픽 환경에서 실행했습니다. 다운로드와 캔버스 실행 여부는 측정하지만, 실제 PC의 FPS 향상이나 물리적인 마우스 지연 개선을 뜻하지 않습니다. 게임 판정이나 기존 리플레이 규칙은 변경하지 않았습니다.
