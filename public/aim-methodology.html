정밀 감도 연구실.
측정하고, 비교하고, 다시 검증합니다.

기존 VALOPRAC의 입력·무기·이동·전술 맵을 유지하면서 감도 실험을 확장했습니다. 한 사람에게 하나의 완벽한 감도가 있다고 가정하지 않습니다.

정밀 감도 연구실기존 훈련장실행 검증 데이터전체 소스와 연구 문서에임 연습 소개

실제 참가자의 향상 효과는 미검증입니다. 이 개발 작업에서 사람 대상 실험은 진행하지 않았습니다. 합성 데이터 결과를 사용자 기록으로 넣거나 최적 감도·보장된 향상률로 표시하지 않습니다.

빠른 보정과 정밀 보정

  1. 기준 측정: 현재 감도에서 반복합니다. 빠른 보정은 작은 표적·미세보정·반응형 추적, 정밀 보정은 일곱 중립 과제를 사용합니다.
  2. 범위 탐색: 가까운 후보를 로그 간격으로 만들고, 동일한 표적 시드·난도에서 순서를 교차합니다. 원래 감도는 계속 대조 조건으로 남습니다.
  3. 세부 비교: 유망한 영역과 원래 감도를 다시 측정합니다. 가장 높은 한 번의 점수를 정답으로 간주하지 않습니다.
  4. 보류 검증: 탐색에 쓰지 않은 시드·표적 조건으로 A/B를 비교합니다. 기준 감도가 남더라도 실제 대안 후보를 검증합니다.
  5. 장기 연구: 독립 세션과 날짜별 변동, 24시간 이후 유지 측정을 구분합니다. 다른 입력 환경과 알고리즘 버전은 합치지 않습니다.

빠른 보정의 목표 시간은 약 5–8분, 정밀 보정은 약 20–40분입니다. 획득 속도와 휴식에 따라 달라집니다. 블록을 마친 뒤 중단하고 저장된 계획을 이어갈 수 있습니다. 무효 시도·초점 상실·화면 중단은 유효 표본으로 세지 않습니다.

실제 전술 평가에서는 비조준 감도와 ADS 배율을 독립적으로 비교합니다. 원래 전역 설정은 바뀌지 않습니다. 이동·반동·산포·조준 배율 불일치는 따로 기록하고, 잡음이 큰 실전 점수를 중립 실험과 원점수로 평균하지 않습니다.

입력 보정과 측정 한계

회전각 = 전달 상대 델타 × 감도 × 각도 계수. eDPI = 신고 DPI × 감도. 예상 cm/360° = 914.4 ÷ (신고 DPI × 감도 × 각도 계수). 예를 들어 800 DPI·0.35·0.07이면 약 46.65cm입니다.

0.07은 KovaaK 개발자의 공식 VALORANT 배율 안내로 대조한 독립 구현 기준입니다. Riot의 엔진 명세나 물리 센서 검증을 뜻하지 않습니다. 웹사이트는 DPI를 읽거나 운영체제 가속을 변경할 수 없고, JavaScript 이벤트 빈도는 하드웨어 폴링 빈도가 아닙니다.

기록에는 신고 DPI·계수·FOV·실제 측정 캔버스 비율·입력 승인 상태·ADS·줌·무기를 포함한 환경 지문을 남깁니다. 감도는 비교할 변수이므로 환경 지문에서 제외합니다. 메뉴 창의 비율과 측정 캔버스 비율을 같은 값으로 간주하지 않습니다. 지원 시 가속 제거 포인터 잠금을 요청하고 거절되면 일반 잠금으로 대체합니다.

표적의 화면 제출 자세와 클릭의 원래 단조 시각을 연결합니다. 기록은 CPU 화면 제출 기준이며 디스플레이 발광 시각이나 물리 input-to-photon 지연을 측정한 것이 아닙니다. 일반 훈련 입력 경로를 공유하고 통계 계산은 마우스 콜백에서 실행하지 않습니다.

추천과 불확실성의 규칙

  • 과제마다 같은 조건의 기준 대비 차이를 기준 변동으로 정규화합니다. 전술·정밀·추적·균형 우선순위는 공개된 설계 가중치이며 보편적 과학 상수가 아닙니다. 비교값 0.5는 기준점이지 실력 백분율이 아닙니다.
  • 완료된 반복 블록과 세션이 통계 단위입니다. 입력 수천 개를 독립 표본으로 세거나, 중복 가져오기·재시도 기록으로 표본 수를 늘리지 않습니다.
  • 평균·중앙값·변동, 짝 차이와 Student-t 구간을 보고합니다. 후보 선별과 과제별 비교에는 다중 비교 보정을 적용합니다. 보류 검증은 별도 세션에 묶인 불확실성을 사용합니다.
  • 개선·저하·실용적 동등·판단 유보를 구분합니다. 구간이 겹친다는 이유로 동등하다고 부르지 않습니다. 임시 실용 차이 기준은 ±0.02이며 정밀도 손실을 속도 점수로 가리지 않습니다.
  • 추천 범위는 시험한 후보의 동등 범위 또는 아직 탈락시키지 못한 범위로 구분합니다. 시험하지 않은 중간값까지 보장하지 않고, 관측된 나쁜 구간을 사이에 두고 좋은 영역을 하나로 잇지 않습니다.
  • 반복 기준선의 순서 효과는 학습·피로 가능성을 경고합니다. 제한된 자료로 원인을 확정하거나 인과효과를 주장하지 않습니다. 예산·안정·피로 중단 조건과 휴식 안내를 제공합니다.
  • 충분한 후보·반복이 없으면 예측 곡선과 구간을 그리지 않습니다. GP 모형 구간은 가정에 의존합니다. 기본값은 해석 가능한 단순 탐색이고 베이지안 탐색은 선택 사항입니다.
  • 일반 연습 도중 감도를 자동 변경하지 않습니다. 적용은 사용자가 승인한 뒤에만 이루어지고 적용 전 값으로 복원할 수 있습니다. 방향별 이득·자동 조준·입력 유도는 없습니다.

실행 검증과 실제 사람의 효과

합성 검증은 정밀도·추적 우위, 넓은 평탄 구간, 좁은 최고점, 분리된 유효 영역, 큰 잡음, 학습·피로, 자료 부족의 아홉 조건을 사용합니다. 격자·무작위·단계 탐색·GP를 동일한 관측 예산으로 비교하며, 기준 재측정과 독립 보류 관측도 예산에 포함합니다.

일반 조건은 방식별 48회, 자료 부족 조건은 8회 관측입니다. 12개 고정 난수 시드 × 9조건 × 4방법의 432회 실행에서 손실·안정성·실용 범위 도달·판단 유보·오판·구간 포함률·CPU 비용을 기록합니다. GP가 모든 조건에서 이기지 않았고 일부 모형 구간은 실제 합성 응답을 충분히 포함하지 못했습니다. 실패도 실행 보고서에 공개합니다.

독립 Gaussian 짝 차이 조건의 800회 반복 검사에서는 95% 구간이 실제 차이를 포함한 횟수와 비율을 그대로 보고합니다. 이는 해당 합성 가정의 구현 검사이며 실제 사용자에게 같은 포함률이나 향상 효과를 보장하지 않습니다. 60·144·240Hz 입력 재생, 입력 순서와 누적 각도, 브라우저 초점·중단, 기존 게임 회귀 검사를 함께 실행합니다.

실제 참가자 0명. 실제 게임 전이, 사람의 장기 향상, 물리 마우스 센서 정확도, GPU 하드웨어 FPS·지연, 다른 브라우저의 동등한 동작은 별도 검증 대상입니다. 실행한 Chromium 검사와 자동 입력 재생을 물리 하드웨어 측정으로 표시하지 않습니다.

보관·내보내기·삭제

자료는 기본적으로 이 브라우저에 저장됩니다. 요약 최대 12,000회, 최근 64회 압축 궤적, 계획 180개, 별도 입력 프로필 최대 20개를 보관합니다. 이전 기록은 보존하며 과거 알고리즘과 환경이 없는 기록은 참고용으로 구분합니다. 에임 기록과 입력 프로필을 내보낼 수 있고 각각 삭제할 수 있습니다. 로그인·외부 AI API 없이 작동하며 궤적을 서버로 전송하지 않습니다.
