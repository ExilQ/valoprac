자유 훈련장

시간 제한이나 점수 목표가 없습니다. 직접 종료할 때까지 같은 세션이 이어집니다. 정지·수평 이동·무작위 방향·이동과 정지·앉기·엄폐물 피킹·무작위 등장 표적을 조정할 수 있습니다. 표적 수, 크기, 이동 속도, 배치 거리와 재등장 간격을 변경하세요. 엄폐물 피킹은 지정 위치의 표적 1개를 사용합니다.

무기 선택, 정상 재장전, 예비 탄약 무제한과 자동 재장전 설정을 지원합니다. 무제한 예비 탄약도 탄창 용량과 재장전 시간은 유지합니다. 기본은 머리만 즉시 제거이며, 자유 훈련에서는 모든 부위 한 발 또는 체력 150의 피해량 누적 규칙을 선택할 수 있습니다. 피해량 누적 규칙에서도 헤드샷은 즉시 제거됩니다.

표적 초기화와 통계 초기화는 훈련을 종료하지 않습니다. 통계 초기화도 경과 시간과 탄약을 유지합니다. 반동 분석용 벽을 켜면 표적을 숨기고 탄착과 반동을 연습할 수 있습니다. 종료 시 훈련 종료 · 기록 저장을 선택하세요. 저장 없이 나가기는 현재 세션을 저장하지 않습니다.

기존 시간제 훈련

  1. 헤드샷 정밀도: 정지 표적의 머리와 첫 발을 연습합니다.
  2. 제동과 카운터 스트레이핑: 키 해제와 반대 방향 입력을 각각 기록하고 비교합니다.
  3. 스프레이 제어: 뒷벽의 탄착군과 보정 궤적을 분석합니다.
  4. 이동 표적 추적: 실제 입체 머리 판정을 기준으로 추적과 방향 전환 반응을 측정합니다.

기준 수치와 추정 모델을 구분합니다.

11.08의 두 소총 좌우 반동 전환 시간 0.6초, 전환 확률 10%, 보호 탄수 밴달 6발·팬텀 8발을 기준으로 삼았습니다. 팬텀의 몸통 피해량 39/35와 20미터 경계도 공식 자료를 참고합니다. 반동 곡선, 전환 기회 해석, 이동 계수, 산포 회복, 장착 시간 등은 추정 모델입니다. 표의 나머지 기본 수치는 요청된 참고값이며 전부를 게임 클라이언트에서 직접 실측하지 않았습니다. 발로란트와 동일한 조작감을 보장하지 않습니다.

사운드 프로필과 음원

밴달: 챔피언스 2023 / 팬텀: 챔피언스 2026 / 셰리프: 아이온을 참고 슬롯으로 구분합니다. 기본 효과음은 모두 자체 제작 대체음입니다. 라이엇 원본 녹음이나 정확하게 복제한 음원이라고 표시하지 않습니다. 원본 음향과의 정밀 비교도 수행하지 않았습니다.

사용 권한이 있는 음원은 사운드 설정에서 발사·재장전·장착·제거 확인 슬롯에 등록할 수 있습니다. 파일당 2메가바이트·8초 이하이며 현재 브라우저에만 저장합니다. 서버로 전송하지 않습니다. 등록한 파일은 다음 훈련부터 적용됩니다. 기본음 복원으로 삭제할 수 있습니다. 무기 전환 시 이전 무기의 소리 노드를 정리하고, 같은 무기의 연사는 잔향이 자연스럽게 겹치도록 처리합니다.

그래픽 설정

원본 환경과 무기를 절차적으로 제작했습니다. 금속·콘크리트·고무 재질, 노멀 맵, 환경 반사, 그림자와 접촉 음영을 적용합니다. 낮음·보통·높음·최고 설정 외에도 렌더링 배율, 그림자, 텍스처, 주변광 차폐, 윤곽선과 효과를 개별 조절할 수 있습니다. 최고 품질은 필수가 아닙니다.

브라우저용 입체 렌더러를 사용하며 언리얼 엔진 자체를 실행하지 않습니다. 144프레임은 목표이며 실제 기기 성능을 측정한 결과가 아닙니다. 그래픽이 느리면 낮음이나 보통 설정과 낮은 렌더링 배율을 사용하세요.

통계의 의미와 보관

명중률은 발사 대비 유효 부위 명중, 헤드샷 명중률은 전체 발사 대비 머리 명중 비율입니다. 첫 발 통계는 연사 묶음의 첫 발입니다. 평균 제거 시간은 표적 생성부터 제거까지입니다. 방향 전환 반응은 2초 이내에 머리를 다시 조준한 지연이며, 사람의 순수 반응속도와 같지 않습니다.

제동 시간은 정확도 속도 기준까지의 시간과 완전 정지·방향 반전까지를 구분합니다. 사격 시점의 음수는 기준 통과 전, 양수는 통과 후입니다. 기준에 도달하지 않은 측정은 비어 있습니다. 중간에 반대 방향 입력을 사용한 제동 동작은 반대 입력으로 분류합니다.

누적 발사·명중·제거·무기별 통계는 전체 세션을 기준으로 유지합니다. 상세 기록은 최근 최대 2,048발, 제거·반응 기록은 각각 최근 256개로 제한합니다. 탄착 분산과 반응 분포는 보관된 최근 상세 기록 기준입니다. 탄착 그림은 최근 80개 벽 탄착, 실시간 반동 표시는 최근 36발을 사용합니다. 이상적 보정선은 참고이며 무작위 산포는 없애지 못합니다.

최근 40회의 세션 요약과 10회의 상세 데이터를 저장합니다. 브라우저 데이터를 지우거나 다른 기기에서 열면 기록과 사용자 음원은 공유되지 않습니다.

감도와 브라우저 입력

회전각 = 마우스 상대 이동량 × 감도 × 계수입니다. 기본 계수 0.07도/카운트는 임시값입니다. 정조준 감도는 기본 감도 × 정조준 감도 ÷ 배율로 적용됩니다. 마우스 해상도 입력은 회전 거리 추정에 사용하며 실제 마우스 장치의 해상도를 바꾸지 않습니다. 추가 시점 평활화는 적용하지 않습니다. 원시 상대 입력을 요청하지만 미지원 환경에서는 운영체제와 브라우저 처리가 남을 수 있습니다. 네이티브 게임과의 1:1 감도 일치를 검증하지 않았습니다.

실행한 자동 검사는 같은 입력을 30·60·144·240회/초 렌더링으로 모사했을 때의 결과 일치를 포함합니다. 1시간 훈련 검사는 가속된 엔진 테스트이며 실제 브라우저를 1시간 켜 둔 시험이 아닙니다. 이 작업 환경에서 지정된 브라우저 검증 도구를 사용할 수 없어 마우스 잠금·음질·그래픽·실제 프레임 수를 확인했다고 주장하지 않습니다.

실제 브라우저 확인 순서

  1. 크롬과 엣지에서 자유 훈련을 열고 시작·잠금 해제·재시작·탭 전환을 확인합니다.
  2. 밴달의 단발·점사·연사·정조준을 연습하고 팬텀으로 바꿔 발사 속도와 반동·소리가 달라지는지 확인합니다.
  3. 셰리프를 누른 채 유지했을 때 한 발만 나가고 정조준이 되지 않는지 확인합니다.
  4. 크기·이동·앉기·피킹 표적의 머리와 몸통을 맞혀 기본 머리 전용 제거를 확인합니다.
  5. 제동·이동 사격·반동 보정·정상 재장전을 확인합니다. 통계와 표적을 바꾸어도 세션이 유지되는지 확인합니다.
  6. 그래픽 네 단계를 각각 실행하고 실제 기기에서 1080 해상도의 프레임 시간과 조준 가독성을 비교합니다.
  7. 설정과 기록을 저장하고 새로고침합니다. 권한 있는 음원 등록·복원도 확인합니다.
  8. 장시간 무기 전환·표적 재생성·훈련 종료와 재입장을 반복하여 그래픽·자바스크립트·소리 자원 사용을 확인합니다.
  9. 기존 시간제 네 모드가 설정 시간에 종료되고 기록을 남기는지 확인합니다.

발소리 누적과 코너 피킹

훈련 준비 화면에서 코너 피킹 맵을 고르세요. 달리기의 실제 이동 거리가 누적되고, 걷기 전환은 잔여량을 바로 비우지 않습니다. 실제로 멈추면 회복됩니다. 지도 원은 임계값을 넘은 발소리 위치의 청취 반경이며, 누적 게이지와 다릅니다.

발소리 검증 결과 · 설정 → 훈련에서 회복 프로필과 현재 설정 비교를 사용할 수 있습니다. 수치는 임시 모델이며 실제 게임과 동일하다고 검증하지 않았습니다.
