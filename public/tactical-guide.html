훈련장 열기

이동 중 사격

달리기와 걷기는 실제 속도에 따라 탄착을 넓힙니다. 이동 키를 놓거나 반대 키를 누른 뒤에도 속도가 남아 있으면 이동 오차가 유지됩니다. ‘이동과 정확도’ 패널이 준비 상태로 바뀌는 순간을 확인하세요.

기본 자세·비정조준·연사 산포가 회복된 상태의 설정값입니다. 앉기·정조준·공중·착지·연사 상태에 따라 달라집니다. 이 훈련장의 산포 분포와 속도 곡선은 보정 모델입니다.

톡브레이킹 순서

  1. A로 충분히 이동한 뒤 D를 짧게 누릅니다. 반대 방향 과제에서는 D → A입니다.
  2. 현재 속도와 정확도 준비 상태를 확인합니다.
  3. 제동 구간에 머리를 조준하고 첫 발을 쏩니다.
  4. 너무 이른 사격·발사 속도·기준 대비 발사 시간을 비교합니다.

‘키 해제 → 사격’ 과제와 결과를 비교하세요. 반대 키를 계속 누르면 멈춘 뒤 반대 방향으로 이동합니다.

가리지 않는 정조준

밴달과 팬텀은 우클릭 한 번으로 1.25배 정조준을 유지하고 다시 클릭하면 해제합니다. 작은 중앙점의 색과 크기는 설정에서 바꿀 수 있습니다. 셰리프는 확대되지 않습니다. 실제 반동은 정조준 중에도 유지됩니다.

표적 속도

표적 설정에서 ‘실전 속도 · 최대 5.4미터/초’를 선택하세요. 짧은 스트레이프와 제동 구간에서는 최고 속도에 도달하지 않을 수 있습니다. 처음에는 절반 속도로 정확하게 따라간 뒤 속도를 올려 보세요.

모든 구역은 자체 제작 훈련 공간이며 공식 발로란트 지도는 아닙니다. 바닥 번호를 따라 각을 정리하고 모두 제거하면 일시정지 메뉴에서 표적을 초기화하세요.

적 시야 노출 사망

적이 플레이어를 실제로 볼 수 있는 동안 노출 시간이 쌓입니다. 노출 제한 모드를 선택하면 기본 3초이며 훈련 설정에서 바꿀 수 있습니다. 연속 모드는 완전히 숨으면 초기화하고, 누적 모드는 엄폐 중 서서히 회복합니다. 발소리만 들었다고 노출 시간이 쌓이지 않습니다.

사망하면 놓친 각과 노출 시간을 확인하고 같은 맵에서 바로 재시도할 수 있습니다.

탄착군 비교

이동 중 사격 과제의 분석 벽에 정지·걷기·달리기·제동 사격을 남겨 보세요. 탄착 폭과 지름, 발사 순간 속도를 함께 비교하면 이동 오차와 반동을 구분하는 데 도움이 됩니다.

전투 방식과 수비수

각 학습은 피해 없이 각을 익히는 방식이고, 교전 훈련은 실제 탄도 피해로 승패를 판정합니다. 노출 제한은 설정 시간으로 판정하는 별도 방식입니다. 보통 수비수도 인지·반응·조준 시간이 필요하며 반동·산포·장전과 불완전 보정이 적용됩니다. 실력과 고급 설정을 조절할 수 있습니다.

발소리와 실제 제동

실제로 감속해 조용한 속도 구간에 들어가면 잔여 누적이 회복됩니다. 반대 키를 누른 사실만으로 초기화되지 않습니다. 높은 속도로 A/D를 반복하면 발소리가 계속 발생하며, 걷기로 바꾸어도 잔여 누적이 유지됩니다.

버니합 훈련

착지 직전에 점프 키를 새로 눌러 연결하세요. 기본 입력 버퍼는 80ms이며 0~140ms 범위로 조절합니다. 키를 계속 누르는 자동 연속 점프는 없습니다. 공중 조작은 기존 관성을 즉시 돌리지 않으며 속도 상한은 5.5m/s입니다. 새 훈련장에서 경사로·계단·플랫폼을 통과하고 입력 시점·속도 보존을 비교하세요.

월샷 훈련

목재·강판·보강벽의 측면에서 표적 위치를 확인하고 숨은 뒤 사격하세요. 밴달·팬텀은 중간, 셰리프·오퍼레이터는 높은 관통 분류를 사용합니다. 경사 입사는 실제 통과 거리가 길어져 저항과 피해 감소가 커집니다. 재질·두께·다중 표면과 남은 관통 예산을 계산하며 보강벽은 통과하지 못합니다. 진단을 켜면 정지 이유를 확인할 수 있습니다.

‘경량 파손 패널’은 관통 재질 분류입니다. 현재 지형이 파괴되거나 삭제되지는 않습니다. 유리도 시야 판정은 고체로 유지됩니다.

빠른 재시도

재시도하면 선택 무기·감도를 유지하고 체력·탄창·예비탄·장전·볼트·스코프·반동·입력·현재 발소리 누적·봇 인지를 초기화합니다. 누적 훈련 통계와 세션 시간은 보존됩니다.

이동·AI·관통 수식은 VALOPRAC의 공개된 임시 보정 모델입니다. 실제 발로란트의 비공개 수식이나 계급별 인간 반응을 재현했다고 주장하지 않습니다. 실행 검증 데이터에서 범위를 확인하세요.

실제 화면 비교

같은 1366×768·Low·렌더 배율 0.5 설정의 실제 브라우저 캡처입니다. 소프트웨어 GPU 환경이며 실기기 화질·FPS 검증을 대신하지 않습니다.

09.00 · 이동 물리 선택과 공중 조향

설정 → 조작 → 이동 물리엔진에서 발로란트 또는 카운터 스트라이크를 선택합니다. 모든 기존 훈련과 맵에 적용되며, 기본은 발로란트입니다. 공중에서 A·D·W·S와 마우스 회전을 함께 사용해 실제 가속과 궤적을 조절합니다.

카운터 스트라이크의 기본은 CS2 공개 패치를 참고한 보정 모델입니다. 클래식 Source는 별도 고급 규칙이며, 어느 설정도 점프 키 유지로 자동 버니합을 수행하지 않습니다. 선택형 휠 점프와 실제 점프 입력 창, 물리 진단은 조작 탭의 고급 항목에서 설정합니다.

전환 시 위치·수직 속도·감도·무기 회복은 보존하며 수평 이동과 대기 입력을 초기화합니다. 실제 착지에는 전용 소리가 발생하고, 공중 이동으로 보행 발소리가 쌓이지 않습니다. 서로 다른 물리 모델의 전술 분석 기록은 합산하지 않습니다.

이동 검증 결과와 측정값 · 공식 CS2 업데이트

계수는 독립 보정값입니다. 네이티브 VALORANT·CS2 엔진과 완전 일치하거나 실제 게임 실력 향상을 보증하지 않습니다. 한 물리 틱 안의 반대 방향 입력은 평균화하며, 전체 네이티브 서브틱 엔진을 복제하지 않습니다.

09.01 · 이동·줌·사운드·그래픽 보정

발로란트 물리의 걷기·앉기·무기·정조준 요청 속도를 공중 가속에 반영합니다. 같은 입력의 도약으로 저속 상태가 달리기 속도까지 가속되던 문제를 수정했으며, 이미 얻은 관성은 갑자기 지우지 않습니다.

조준 카메라의 가로 시야각은 기본 FOV ÷ 배율입니다. 기본 103도에서 1.25배는 82.4도, 2.5배는 41.2도, 5배는 20.6도입니다. 설정 → 조작의 정조준·키 지정에서 소총·2.5배·5배 감도를 따로 정하고, 한 바퀴 회전에 필요한 전달 카운트를 확인합니다. 센서 카운트를 직접 측정한 값은 아닙니다.

미리 조준한 수비수는 실제 인식·반응·조준 오차·무기 회복을 거쳐 첫 발을 발사합니다. 20m·64개 시드의 보통 설정 중앙값은 0.72초에서 0.39초로 바뀌었습니다. 인간이나 실제 게임의 반응 분포를 검증한 수치는 아닙니다.

적 총성과 실제 이동으로 발생한 봇 발소리에 공간 음향을 적용하고, 오래된 연사음을 버려 지연음이 한꺼번에 겹치는 현상을 줄입니다. 소프트웨어·내장 그래픽으로 감지되면 안내와 낮음 자동 적용을 제공하며 직접 고른 품질을 유지할 수 있습니다. 훈련 그래픽을 준비하고 첫 실제 화면을 그린 다음 시작 버튼이 활성화됩니다.
