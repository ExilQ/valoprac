기존 무기·훈련·감도 연구실을 유지한 브라우저 엔진 업데이트입니다. 발로란트와 정확히 같은 내부 물리나 실제 언리얼 실행을 주장하지 않습니다. 이 환경의 브라우저는 입체 그래픽이 비활성화되어 실제 화면 품질·물리 마우스·고주사율 성능은 미검증입니다.

시작 방법

  1. 훈련 준비에서 톡브레이킹 과제 또는 새 전술 맵을 선택합니다. 기존 자유·시간제·반동·추적 훈련도 사용할 수 있습니다.
  2. C는 안전한 기본 앉기입니다. 설정 → 조작에서 앉기와 정조준의 토글·유지 방식을 바꿀 수 있습니다.
  3. 밴달·팬텀은 우클릭 한 번으로 정조준하고, 다시 클릭하면 해제합니다. 기존에 저장한 유지 방식은 보존합니다. 셰리프는 확대되지 않습니다.
  4. 마우스 잠금은 시작 클릭으로 요청합니다. 전체화면·키 잠금 시작은 지원 브라우저에서만 단축키를 캡처합니다. 키 잠금을 확인하지 않은 탭에서는 Ctrl+W가 탭을 닫을 수 있습니다.
  5. 새 맵에서는 바닥 번호를 따라 각을 하나씩 정리하세요. 모든 표적을 제거한 뒤 일시정지 → 표적 초기화로 다시 배치합니다. 시야 노출 사망 후에는 즉시 재시도할 수 있습니다.

실제 이동과 사격

이동 키를 놓아도 속도는 즉시 0이 되지 않습니다. 반대 방향을 입력하면 가속도가 기존 속도를 줄이고, 계속 누르면 반대 방향으로 움직입니다. 탄도는 발사 순간의 실제 속도·앉기·공중·착지·연사 산포·반동을 따로 반영합니다.

톡브레이킹 과제는 시작 방향·반대 키·정확도 구간·머리 명중을 따로 검사합니다. 키 놓기 과제와 제동 결과를 비교할 수 있습니다. ‘이동 중 사격’은 분석 벽에서 실제 탄착·가로/세로 폭·지름·각 산포·발사 속도·정지 후 시간을 표시합니다. 반동은 감도 오류와 분리됩니다.

정조준 시야

확대는 실제 카메라 시야각의 탄젠트를 1.25로 나눕니다. 무기 표현에는 별도 고정 시야각 카메라를 사용해 몸체를 조준선 아래에 배치했습니다. 가는 개방형 가늠자와 작은 중앙점만 사용하며 검은 스코프 테두리나 주변 흐림은 없습니다. 시각적 흔들림 조절은 실제 반동·탄도를 바꾸지 않습니다.

발소리 회복

정지 속도 기준과 회복 대기는 그대로 두고 정지 회복을 초당 1.4에서 3.5로 높였습니다. 걷기 회복은 초당 0.02이며 잔여 누적은 유지됩니다. 약 85%에서 완전히 정지한 비교는 아래 실제 테스트 결과에 표시합니다. 미니맵 원은 발생한 소리의 청취 반경이고, 누적 게이지와 별개입니다.

시야 노출 사망

기본 2초이며 0.5–5초로 조절할 수 있습니다. 반응 준비가 끝난 살아 있는 적의 감지 영역에서 머리 또는 몸통까지 사선이 뚫려야 시간이 쌓입니다. 소리를 들었다는 이유만으로 노출이 누적되지 않습니다. 연속 모드는 완전 엄폐 시 초기화하고, 누적 모드는 엄폐 중 천천히 줄어듭니다. 사망 화면은 적·놓친 각·노출 시간·위치·교정 안내를 보여줍니다.

입력과 성능 검증

원시 상대 입력을 요청하되 요청 수락과 센서 경로 검증을 구분합니다. 설정 → 조작의 입력 진단은 전달 이벤트 빈도·콜백 처리 시간·전달 지연을 표시합니다. 센서 주파수나 마우스를 움직인 뒤 화면이 바뀌는 전체 지연을 측정한 값은 아닙니다. 운영체제 가속 설정을 바꾸지 않으며 방향별 감도 보정·자동 조준·입력 유도를 사용하지 않습니다.
